# pao配置

pao 自身运行时配置的唯一归属（2026-10-02 建，K3 审查 R13 补占位）。

## 现有文件

- `档位.json` — 两档虚拟模型配置（快/主力，GLM 映射＋思考档差异；M1-04 落定，随 `PAO_HOME` 指向的根被 `src/pao/routing/config.ts` 读取）。换物理模型只改此文件。
- `装载清单.md` — 主控/worker（及未来部长）各自的扩展与工具清单＋隔离机制＋代码接线锚点（R10 留档正本，M1-04 建）。
- `skills/` — 移植进 pao 的高频技能（当前 commit、codebase-memory 两件；经用户级 settings 的 `skills` 字段挂入 pi，装载与兼容记录见装载清单 §5）。

## 规划中（随对应功能实施落文件）

- `记忆.json` — §18.5 记忆供应商选择（供应商名＋参数，换供应商＝改配置）
- `models.json` 涉凭证部分不落此处，走 `.env`（GLM_*/EMBED_* 占位纪律）

## 边界

- `PAO_HOME` 指向 pao 工作区根（含本目录与 `部门/`；当前 `D:\AI\workspace\pao`）。
- 本目录文件一律不含密钥；凭证走环境变量或 `.env`（不入库、不进日志）。
