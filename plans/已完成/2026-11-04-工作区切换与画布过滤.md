# 工作区切换与画布过滤计划

建稿及事实核实日期：2026-11-04。状态：**已完成（2026-11-04 全部批次终审通过）**；批次执行状态只维护在 §7。

本文件是实施规格。需求来自用户对话定案（2026-11-04）：画布左上角工作区可选（含移除已登记文件夹）、实例列表全局显示且标注所属文件夹、点实例自动切到所属工作区。验证证据归 `.pao/工作区切换画布过滤-2026-11-04/`。

## 1. 目标

让画布的工作区成为可选上下文：左上角下拉切换已登记文件夹、选新文件夹或移除已登记项；画布实例/异常列表全局显示并标注所属文件夹；配方库全局列出所有配方（配方存 PAO_HOME 一处），点实例自动切到它所属的工作区。

## 4. 实施口径

**已确认事实**：配方在 PAO_HOME 全局（无文件夹归属）；实例存项目 `.pao/` 绑文件夹；实例行 `path` 是 `<项目根>\.pao\...\工作流实例-X.md` 绝对路径可前缀反查；左上角 `topbar.tsx:48` 现只读显示 `rootWorkspace.name`。

**批 A — 实例列表全局显示+归属标注（renderer，零契约改动；2026-11-04 方向变更）**
- **定案变更**：首版按「当前工作区过滤」实施后发现与核心需求冲突——过滤后看不到也点不到其他工作区的实例，「显示所有工作流、点了直接切过去」不成立。用户定案改全局显示（方案甲）：列表不按工作区过滤，每行标注所属文件夹；点击走批 D 跳转。
- 列表取全量 `result.instances`+`anomalies`；每行经 `workspaceIdForInstancePath`（批 D 已建：前缀反查+`resolveRepoWorkspaceId` 归并）求所属工作区，显示其文件夹名；未登记如实标注。
- 空态语义改回全局口径（「暂无运行实例」等），不再依赖 selectedWorkspace。
- 不沉到内核：契约/IPC/envelope 全不动，renderer 侧标注。
- 首版按过滤实施并已验的代码（`instanceBelongsToWorkspace`、scoped 过滤、无工作区空态）按本变更回退；`workspaceIdForInstancePath` 归属反查保留并复用。

**批 B — 左上角工作区下拉**
- `topbar.tsx` 工作区名改下拉：选项源 `rootWorkspaceOptions`（workspace-context.ts:56-64 去重 root 集）+「选择新文件夹…」项。
- 放顶栏（非画布头部）：`rootWorkspace.name` 已在那，就地升级；切工作区是全 app 行为，画布专属会误导。
- **非画布视图选下拉→留在当前视图**（已定，不沿用「跳 threads」）。

**批 C — 切换不切视图（IPC 层，B/D 前置）**
- `addPickedWorkspace`/`pickWorkspace` IPC 加 `keepView` 选项（缺省 false 保旧行为）：现在选新文件夹强制 `setActiveView("new-thread")`（main.ts:908）。
- `selectWorkspace` 加可选参数 `stayInView`（或新变体）：现在它硬 `activeView:"threads"`（app-store-workspace.ts:266），侧栏多处依赖，不动默认，加参数。
- 画布下拉选已登记项/新文件夹都传 keepView/stayInView。

**批 D — 实例→所属工作区跳转**
- `renderInstanceRow` 点击前置：实例所属 workspace=`desktopPathKey(instance.path)` 前缀反查 `snapshot.workspaces[].path`，命中经 `resolveRepoWorkspaceId` 归并。
- 非当前→先 `selectWorkspace`（过 `runLeavingWorkflow` 守卫，防画布丢草稿）再 `openSelection`；当前→直接 `openSelection`（复用 App.tsx:1270 `onOpenWorkflow` 两段式先例）。
- 所属文件夹未登记→如实提示「该运行记录所属文件夹未登记为工作区」，不静默登记（渲染层无 addWorkspace 通道是刻意的）。

**批 E — 配方库全局与点配方口径（2026-11-04 用户定案：点配方保持编辑器）**
- **点配方=打开编辑器（现状保留）**：点配方行进画布编辑器改节点/脚本；启动走右下角「启动向导」，向导已用 `initialRecipeName` 自动预填当前选中配方（wizard.tsx:102-115 现成）。
- 配方天然全局存 `<PAO_HOME>/工作流/`（无文件夹归属），配方库「我的」页签即全局列出——无需新建归属关系。
- 启新实例绑当前工作区 project（`parameters.项目===project` 内核强制）；无 identity 时启动按钮禁用（canInstallTemplate/onOpenMasterSession 守卫）。
- 本批主要是核对确认既有行为满足验收，不改点击默认行为。

**批 F — 工作区下拉项移除（×）（2026-11-04 用户追加）**
- `WorkspaceSwitcherMenu` 每个已登记项行尾加「×」按钮：行容器改非 button（`role="menuitemradio"` + Enter/Space 键盘），× 用 `stopPropagation` 独立点击，「选择新文件夹…」项无 ×。
- 点 × → `window.confirm`（复用 i18n「从 pi-gui 移除 {name}？不会删除任何文件。」）→ `api.removeWorkspace(id)`（既有全链：IPC→catalog 删除登记，**不删磁盘 `.pao/`/会话文件**，重新添加可恢复）→ 刷新快照→关菜单。
- 删当前选中自动回落剩余第一个工作区（`fallbackSelectionAfterWorkspaceRemoval`）；画布有未保存改动过 `runLeavingWorkflow` 守卫。
- worktree 不级联：删 root 不动其 linked worktree（孤儿条目现有渲染兜底）；不新增 `beginWorkspaceDeletion` 门槛（运行中会话不在本批拦截，登记为限制）。

## 6. 限制与变更

- 不改配方/实例存储位置；配方保持全局（PAO_HOME），实例保持绑项目文件夹。
- 不新建「配方↔文件夹」归属关系；不做同屏并存多工作区工作流。
- 渲染层不新增 addWorkspace 通道；未登记文件夹只提示不登记。
- 界面新增固定文案走 i18n。
- 状态、验收证据只在 §7 与证据报告维护。
