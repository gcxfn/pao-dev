# 全域简洁性审查与重构实施计划

用户于2026-10-22授权更新通用技能，并按技能重构整体代码。完成日期：2026-10-22。唯一执行状态见[执行总册](../未完成/2026-10-17-Harness完善与工作台迭代执行计划.md)§10.16；本文件定义范围和验收，不另维护批次状态。交付与验证限制见[实施与验收报告](../../.pao/全域简洁性重构-20261022/实施与验收报告.md)。

## 目标与现成能力

使用已更新的公共 code-simplicity 技能，以复用、结构质量、运行效率三个方面审核自有业务和 CLI/桌面接入边界，实施有真实收益的重构。复用既有工作流读取器、配置解析、公开 PAO SDK、包装配入口和项目定向测试；不引入新的框架或运行依赖。

技能保留行为与公开契约、按风险验证、整合者复核。清单借鉴 OpenHands 的三方面审查及 Superpowers 的证据要求，未安装上游整套技能，未改 AGENTS。

## 范围与分工

整体指 PAO 自有业务、CLI 关键装配及桌面 renderer/main/IPC、内核接入驱动和契约；上游 pi、历史冻结物、无关营销网站、正式 PAO_HOME 不做无关重写。列出所有自有模块，分别记录深入审读、抽样和未覆盖，不能将文件清单说成逐行审完。

| 分工 | 审查与允许改动边界 | 验证重点 |
|---|---|---|
| 状态与结果 | 核对 workflow/status 的读取与投影；优先消除 results 的重复实例解析与目录发现，写 status 及直接回归 | v1/v2、坏实例、目录错误、深度和顺序；不改持久协议或恢复状态机 |
| 配置与内部状态 | 审查 panel/supervision 及周边；消除一次刷新重复读取，核实内部无用方法 | 缺省、坏 JSON、权限失败与写前保护；不删公开 API |
| 桌面接入 | 审查桌面与 SDK 接入；收拢重复 PAO 模块加载，必要时统一真实重复纯函数 | 公开导出、内嵌发行边界、类型与真实 Electron；保持契约 |
| 其余模块与效率 | 审核上轮未深入的自有模块、调用链与真实资源路径，先给证据；整合者安排必要补充改动 | 不虚构性能提升，不按行数拆文件，不把具体行为修复混入重构 |

补审确认后，本轮补充实施 `workflow/plan.ts` 全列查询的一次采集与 `memory/resident.ts` 同轮投影复用，保留单计划错误、排序、召回失败与纠正提示路径。地图批量 Git 读取及知识扫描异步取消涉及采集语义和锁内更新边界，本批只记录证据，不以未经验证的替换完成重构。

实施由 group/deepseek high 子代理承担互不重叠的文件，主控更新技能、保留源码基线、核查影响面、整合及验收。子代理出现持续服务错误时按已有授权由主控推进。跨边界冲突先汇总，不并发抢改。

## 验收与停止条件

每项改动说明真实调用与重复证据、唯一归属、保留语义和必要验证。修改测试运行对应测试；生产类型与构建、架构门禁按实际影响运行；桌面完成真实 Electron 检查。重构不自动授权真实付费模型测试、全局安装、正式数据迁移或发布。

最终核对整合差异及受影响调用链，删除被替代实现；无法保留语义或需要新产品决定的事项单列。正确模块保留，不为“整体”强行修改每个文件。必要检查通过且没有新的疑点后交付，不无目的循环审查。结果见 `.pao/全域简洁性重构-20261022/`。
