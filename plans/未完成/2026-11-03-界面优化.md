# 界面优化计划（极简高级方向）

建稿日期：2026-11-03。依据：当日与用户讨论确认——全部页面可改、右坞保留可展开、工作流回画布形式（卡片工作台不保留，能力并入画布）、视觉保持现有灰白基调做极简高级。状态：**批次全部已验**（2026-11-03）；后续画布方向由 [2026-11-04 工作流画布升级计划](../已完成/2026-11-04-工作流画布升级.md)承接；余卡片工作台退役待用户确认，确认后本计划归档。

本文件只写目标、边界与验收口径；批次执行状态在 §7 维护，验证证据归 `.pao/界面优化-<日期>/`。

## 1. 目标

把 PAO 自有界面拉到与会话页、设置页同一水准。方向是**极简高级**：保持现有灰白 Codex 基调与 tokens 体系，靠排版、间距、对齐、信息层级做质感，不引入新色彩体系、不加装饰。

## 2. 已确认的产品要求

| 编号 | 决定 | 口径 |
|---|---|---|
| U01 | 范围覆盖全部页面 | 会话、工作流、看板、定时任务、设置、命令面板、侧栏、空态都在范围内；设置与会话页只做打磨不重做 |
| U02 | 右坞保持现状 | 「当前工作概况/当前工作」坞的可展开行为与现有布局不动，仅随零件层统一做轻微样式对齐 |
| U03 | 工作流回画布形式 | 画布（现埋在「模板与旧运行」tab 的 CanvasPage 三区 DAG 视图）重新成为工作流主视图；**卡片工作台不保留**，其「展开这张卡/讨论这一步/停止这张卡」等能力并入画布节点详情与节点菜单，见 §4 批 3 |
| U04 | 视觉保持现状 | 沿用 tokens.css 标尺与 color-mix 主题派生，不改主题 seed、不加新色板；高级感来自密度、对齐、层级与留白，不来自颜色堆叠 |
| U05 | 中文排版微调 | 保守调整：font stack 补 CJK 回退（现状 `--font-ui` 无中文字体，落到系统默认）、行高与字号在小范围内微调；先看对比再定稿 |

## 3. 现状基线（2026-11-03 核实）

已有可复用基础，计划前先复用、不重造：

- `styles/tokens.css`：间距/半径/字号/动效/边框/elevation/状态色标尺完备，颜色全部经 `color-mix` 派生自动适配主题。
- `contracts/theme.ts`：主题 seed 引擎，改动视觉不动它。
- 看板详情 `kanban-board.tsx` 的 `DetailField`/`DetailProse`/`DetailList` 零件：可在其上加分组，不替换。
- 画布 `features/canvas/canvas-page.tsx`：三区布局（左列表、中 DAG、右节点详情）已存在且带总览/详细图/专注/列表、搜索筛选、节点详情；需要做的是把它抬回主视图并打磨，不是重建。
- 会话页、设置页是基准样例：分组卡片、页头层级、紧凑密度照它们对齐。

已确认的粗糙点（截图证据）：

- 看板详情一堵 `<dl>` 键值墙（~15 字段平铺），预算无层级，JSON 原始值外露；标题行「刷新」按钮窄空间挤成竖排；四列在 1280px 窗每列仅 ~160px 卡片挤压。
- 空态全是裸灰字，无统一组件。
- 共享页头 `view-header`（标题+描述+右侧动作）已存在且 8 处使用，但工作流页未接入、看板在其上出现挤压缺陷；各页对齐度参差。
- `--font-ui` 无 CJK 字体回退；中文 11–12px 偏挤偏灰。
- 画布工具条按钮混用中英文（"Start a workflow"/"Refresh" 未走 i18n），失败横幅与节点配色偏饱和。
- 画布大图可读性（用户核心反馈「节点一多就根本看不清」）：节点在任何缩放级别都渲染全卡片（缩小即糊）；折叠规则只收线性链，宽扇出仍全平铺；边常显无 hover 高亮；无「有问题的组自动展开」机制。MiniMap、缩放控件、链式折叠、专注/列表模式、上下游置灰、视口持久化已具备，不在缺口清单。

## 4. 分批实施

| 批 | 内容 | 依赖 |
|---|---|---|
| **1 零件层** | 各页统一到现有 `view-header` 模式并修其边缘缺陷（动作区 `white-space`/`flex-shrink`）；`EmptyState` 共享组件（图标+标题+提示+动作位）；详情字段分组模式（dt/dl 加分组标题）；`--font-ui` 补 CJK 回退；中文行高/字号微调（先出一页对比截图再定值） | 无 |
| **2 看板** | 详情面板重设计：字段分组（基本/执行/预算/时间/正文）、预算改紧凑展示、回执与执行改时间线行、JSON 再收深；修「刷新」挤压；列卡紧凑化（部门章、状态 rail、元信息一行） | 批 1 零件 |
| **3a 画布信息量** | 语义缩放 LOD：zoom ≥0.7 全卡片 → 0.35–0.7 紧凑（名称+状态点）→ <0.35 状态色胶囊；边默认细线无标签、hover 节点高亮其上下游全路径（扩展现有 relatedNames 机制到 hover）；审核回边 zoom <0.35 隐藏；大图默认展开采折中：展开到「第二层」（主干+直接分支），更深组收起 | 批 1 零件 |
| **3b 画布结构收敛** | 折叠规则扩到「同父兄弟扇出 ≥4」收成并行组；组节点显示成员状态汇总条（N 完成/N 进行/N 失败）替代纯文字摘要 | 3a |
| **3c 画布升主视图 + 操作并入** | 画布为工作流主视图；卡片工作台退役，能力并入：节点详情栏承接展开卡/讨论/停止，只读画布开放右键=节点动作菜单；顶部整合 WorkflowRuntimeControls，按钮行统一 i18n 与样式；节点盒、状态色按极简方向收敛（降填充饱和度、统一 stroke）；节点详情沿用批 1 分组字段 | 3a/3b；需先盘点卡片操作清单 |
| **4 全局打磨** | 会话页细节、定时任务、命令面板、侧栏导航副标题统一、hover/focus/过渡一致性、明暗主题回检 | 批 1–3 |

批次内一次只改一个边界，不顺手做无关重构与全库改名。

## 5. 验证方法

- 每批改完：类型检查 + 定向 ESLint + Prettier；架构守卫若涉契约。
- 界面验证走真实 Electron（项目规则）：沿用现有 Playwright 夹具截图，1280px 与 900px 两档宽度、中文界面、明暗两主题（主题相关改动才需双主题），前后对比留档 `.pao/界面优化-<日期>/`。
- 涉及交互路径的改动跑对应 core spec（如看板 `kanban-*`、画布 `workflow-*` 相关用例）；不新增测试车道，不为 UI 改动引入新依赖。

## 6. 边界与待定

- 不改内核契约、投影、IPC；UI 只整理展示，不动数据来源。
- 右坞（U02）、主题 seed、配色体系不动。
- **已定 1**（2026-11-03）：卡片工作台不保留；其操作能力并入画布节点详情与节点菜单（批 3c），实施时先盘点操作清单逐项落位。
- **已定 2**（2026-11-03）：plans/AGENTS.md「当前焦点」指针改指本计划；Harness 总册未验项仍留在其 §10 状态表，不因此关闭。
- **不做**：换 dagre/ELK 布局引擎（自写分层布局对当前 DAG 够用）；zoom 驱动层级自动展开（手动展开+默认第二层已够）。
