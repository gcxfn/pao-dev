## 3. 分阶段任务与验收

### S0：盘点并固定执行依据

- 改代码前查 codebase-memory 图状态、调用链与影响面。工具不可用时如实记录并用源码追踪，不伪称已查图。
- 核已批准契约订正：会话锁、控制正本、命令、构建、搬迁链接；冻结存档不改。
- 盘点真实旧配方／实例，列“可读取／需显式转换／仅历史展示”。没有旧数据就如实写明，使用标注的旧格式 fixture 验证识别和拒绝，不建通用迁移框架。
- 记录模块测试、构建、全量失败问题与可复跑入口；同代码同环境证据可复用。历史基线门尚未通过是 S7 正式未解问题，不可略去。
- 冻结 S4 压缩样本及 S7 三组对照的任务来源、输入、验收、档位、工具菜单、库版本、预算。默认小 bug／明确小功能／跨模块改动各一项，三组共 9 次，属于小规模初测；已有明确批准的样本优先，不自行缩小。
- 同时冻结 S4 默认启用判据：约束与证据正确性不得下降、固定样本合格交付数不得下降；预先声明优先降低费用还是耗时以及可接受取舍，逐任务报告两者。未能确认收益或结果并列时保留旧默认，不事后改门槛；不预编无依据的百分比承诺。
- 核实 UI 自动化能否操作目标 Windows TUI／Electron；能则自主完成，不能则提前列最少手验步骤及需要用户的环节。

验收：开工记录、旧数据清单、冻结样本与验收表齐备；授权缺项明确；所有任务有阶段和证据落位；未删历史失败。费用／真机缺项只阻塞依赖它的真实验收，离线工作继续。

### S1：真实调用、停止与桌面最小适配

任务分两批：

1. 真部长 RPC（进程间请求接口）接本地锁版构建，完成最小任务、失败返回、取消；补 Windows 正常退出／Ctrl+C／强杀／关终端。只结束本轮受管进程树。
2. pi-gui 原样构建启动，driver 接本地 PAO，验证真实请求、流式、取消、退出。实现会话锁；核卡号、登记、基线快照及在途状态跨进程写点。死进程残锁须显式接管，不能仅看 PID 数字就永久占锁；沿成熟锁机制处理身份与残留，不自建全局锁平台。

同步核现有上游额度协调是否跨进程生效；若当前只有会话内预算，须复用现有预算／锁组件补齐共享额度收口，不能只写一条跨窗口验收而缺实现。不得扩大成独立预算平台。

验收：

- 日志可辨真实构建路径／版本／会话身份；模拟进程和真实进程证据分开。
- 四退出后没有受管任务继续发调用或写项目，不能只看父进程退出；用户其他独立会话不受影响。
- 同会话两端不能同时驱动，不同会话能并行；同项目写仍排队，共享上游额度不被多窗口绕过。
- 桌面真实请求、取消、退出均成功才算最小适配；窗口打开不算，不提前宣布基础桌面验收通过。

### S2：引擎 v2、会话桥与启动检查

引用[引擎 v2](存档-收编-2026-10-04/2026-10-03-工作流引擎v2.md)及[桌面计划](存档-收编-2026-10-04/2026-10-02-M3桌面壳.md)，分四批。

**S2a 会话桥（F2）**：核锁版 CLI 参数后保存 worker 会话，落项目 .pao/worker会话/；在途映射落项目编排目录；回执／登记／证据／会话统一执行标识。完成、失败、取消、崩溃都能解释映射状态，迟到结果归原尝试。部长会话按项目＋部门＋脉络落标识。

**S2b 节点与控制状态（F1 第一批）**：节点＝部门；部长分批拆卡、并发上限自动排队；拆解结束后才能判断全部交付。部门名额／项目写锁／上游额度分列。图运行期冻结，实例清单存进度／轮次／会话／owner。旧实例先识别格式，不按 v2 盲续跑；转换产生新副本并保留原件及关系。缺控制信息时拒自动恢复，给人工重建摘要。

**S2c 判定与回边（F1 第二批）**：pass／change／reject；判定包带卡面、diff、验收证据、派单理由和两轴判断；新轮次打回使受影响下游失效，无关分支保留。上限、重试升档、裁定开关、超限两动作遵循定案；单卡验收与节点判定互不替代。回边 0＝不限次数仍受预算、取消和主会话生命周期限制。

**S2d 启动检查＋终端待处理**：检查项目／PAO_HOME、参数、部门／技能、档位、必需配置、权限、预算及锁。默认只读，不落卡、不 spawn、不自动改配置、不付费探测。结果分“阻止启动／可排队／警告／未验证”；占锁显示等待，不一律拒绝；可选记忆离线按既有降级处理。实际启动仍经原派发入口重核可变条件，预检不是永久通行证。待处理复用首跑清单，显示原因／待决定／建议／证据。

验收：

- 覆盖存档完整测试面；真实入口验证多卡汇合、一次打回、失败停止、取消、人工恢复；确定性异常注入标模拟，不伪造真实模型判定。
- 旧回执、旧轮次、跨项目同号不推进当前实例；缺拆解结束信号不能完成，零卡结束语义明确，不意外空完成。
- 清单损坏不伪造恢复；恢复核现场改动与 owner，人工决定后续跑；控制正本不可当缓存清理。
- 预检无副作用；必需项缺失阻断，可选降级不误阻断；检查后配置改变仍由启动入口捕获。
- 超限显示“按配置放行，仍有未解决项”，缺证据不冒充审核通过。
- 真实会话 JSONL 有增量，失败／取消仍可定位；待处理跳到正确项目、卡和尝试。

### S3：召回迁移、记忆纠错与上下文查看

**S3a（F3）**：静态规则留系统提示，动态召回迁消息层；明确稳定前缀、追加和必要失效边界。压缩前保存最新约束、未完事项、工具错误、待确认项，之后恢复。账本保留原始 usage，缓存／输入／输出不重复计费；任务态摘要不能混成跨会话用户事实。

**S3b（记忆来源与纠错）**：显示本次实际注入的来源、准确 ID、内容、作用范围；缺时间／置信度写未知。提供“本会话不再采用此条”“提交纠正”“忘却”。排除只影响本会话，不能谎称能撤回已发送内容；后续请求明确纠正旧事实。共享写入显示原文、新文和影响范围，遵守现有许可和确认。

当前通用供应商接口没有更新事务承诺：优先复用实际支持的更正／替代语义；只能写新再忘旧时明确两步操作，保留新条目写入证据，失败显示部分成功，不能谎报原子更新。不支持忘却或没有准确 ID 时解释能力边界，不假报成功；不另建记忆数据库。

**S3c（上下文查看）**：先接终端面板，S5 桌面复用同数据；显示真实装配的系统规则、消息、技能、工具说明、召回、压缩摘要和删减原因。区分待发预览／已发送请求，按需查看不触发模型；不展示隐藏推理。供应商内部内容不可见则明示；token 估算写估算；密钥不入视图／日志。关联既有请求／会话，不常驻复制全部输入。

验收：检索词变化不重写静态前缀；压缩保留最新纠正与待办；召回关闭、断链、无 ID、更正半失败、取消确认均诚实展示。真实供应商写→召回→纠正→再召回→忘却在授权测试范围验证。查看页对照实际请求装配，不只列“可能被读取”的文件；已发送历史不能改成“从未发送”。

### S4：输出修剪、预压缩与 TUI

分开实施、检查，避免所有改动混在一起：

1. 同文件重读修剪旧输出：区分版本，用户比较／diff／诊断还需要旧内容时保留；失败读取不覆盖最后有效结果。
2. 废输出与命令压缩表：保留退出码、错误原因、诊断行和完整原文定位；未知命令保留原行为。无匹配／超时也可能是证据，不一律删除。
3. 异步预压缩：摘要绑定开始时的上下文版本；期间新消息保留为后续部分。取消、切会话、已压缩、版本不兼容时丢弃过期摘要；兼容才应用，不承诺任何时候零停顿。失败回既有压缩路径，不扩建多方法框架。
4. F5：页脚只留 PAO 用量、用户消息边框复用现成渲染；核长中文、换行、窄窗、滚动。

验收：先过约束／错误／差异不丢的正确性，再用 S0 样本对照原行为和新行为；计合格交付、全角色费用（含最终丢弃的预压缩调用）、时间、介入、缓存状态。失败不剔除，缓存未知不填冷启动；无未配对工具消息、无跨会话内容。正确性未过不能启用。正确性过但收益不足，可交付完整实现并保持原默认路径，如实报告，不无限调到漂亮数字才结束。
