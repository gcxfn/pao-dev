## 二、工作流视图定稿（四区布局）

```
┌───────────────────────────────────────────────────────────────┐
│ [视频制作 ●] [小说] [优化] [+]                    工作流标签 │
├───────┬────────────┬──────────────────────────┬───────────────┤
│ Pi    │ 配方库     │ 工作流编辑工具栏         │ 编辑信息/属性 │
│ 原生  │            ├──────────────────────────┤               │
│ 导航  │ 搜索       │                          │ 工作流属性    │
│       │ 最近       │       自由工作流画布      │ 节点属性      │
│ 可折叠│ 我的       │                          │ 连线属性      │
│       │ 模板       │  节点 ——→ 节点          │ 条件配置      │
│       │            │       ↘                  │               │
│       │            │        节点              │               │
│       │            ├──────────────────────────┤               │
│       │            │ ▾ 主控对话               │               │
│       │            │ 可折叠 / 可拖动调整高度   │               │
└───────┴────────────┴──────────────────────────┴───────────────┘
```

产品语义表：

| 部分 | 最终需求 |
|---|---|
| 顶部标签 | 一个标签＝一个工作流工作空间；预设工作流可常驻；`+` 建空白工作流 |
| 配方库 | 点击立即加载；搜索/最近/我的/模板；可折叠 |
| 画布 | 自由坐标、拖动节点、手动连线、增删节点、框选多选、缩放、Fit、MiniMap |
| 自动布局 | 可有「自动整理」按钮，**绝不强制自动分层** |
| 编辑对象 | **配方**，不是运行中的实例 |
| 保存 | 保存/另存为/放弃修改；修改后标签 `●` dirty |
| 右侧（编辑态） | 工作流/节点/连线属性 Inspector（Name/Model/Thinking/Prompt/Inputs/Outputs/Retry/Timeout 等） |
| 底部 | 主控对话；属于整个工作流；可折叠、可上下拖动；**内嵌新建对话**，不跳转已有对话（推翻 P4-4 跳转语义） |
| 启动 | 当前配方生成不可变快照，再启动实例 |
| 运行态 | 画布位置不变、**锁定编辑**、节点显示执行状态（六态着色沿用） |
| 右侧（运行态） | 实例信息/当前节点/输入/输出/日志/错误/耗时/Token 费用 |
| 主控对话（运行态） | 可问运行情况、停止实例、分析失败、要求优化 |
| 修改运行中流程 | 不直接改实例；停止/回编辑态→改配方→新建实例 |

概念链（与「实例冻结」红线同义）：

```
Recipe 配方 ──一键启动──▶ Snapshot 不可变快照 ──▶ Instance 运行实例
（画布编辑对象）          （按当前画布冻结）        （卡＋Pi 会话，只读渲染）
```

## 四、本地修正四则（外部方案不知道的事实）

1. **配方 schema 落在既有 parseRecipe 文本格式上扩展**（nodes/edges/positions 作为扩展字段，如 `recipe.ui.positions`），不另起 JSON 新 schema；卡协议 14 字段中文键冻结不动。
2. **画布不是白纸起步**：现状 P4-2/4 已有只读画布（自动分层＋SVG 直线边＋六态着色＋D8d 节点详情）。新编辑器＝**替换渲染层**，运行态着色与节点详情要接新画布保留，P4 已验收能力不丢。
3. **WorkflowTabState 持久化走 ui-state 白名单**（tabId/recipeId/controllerSessionId/dirty/selectedElementId/instanceId/mode）——白名单＋校验器一次过（AppView 三处清单不同步真机崩溃教训）。`controllerSessionId`＝标签绑定的新建对话。
4. **不外发仓库地址**：fork 私有仓不可推；代码对位与改造任务书由主会话基于本地仓自出。
