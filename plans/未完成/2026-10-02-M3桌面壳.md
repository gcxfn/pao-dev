# M3 桌面壳

建稿：2026-10-02。状态：**完整计划已编制；待终端核心稳定后执行**。

依据：需求 §1/§5/§6，架构 §2.2/§8.9。用户要的是独立桌面入口，但内核依旧为外部锁版 pi＋PAO，不另造 agent 产品。

## 目标

桌面里能对话、选项目/档位、派卡与取消、查看队列/回执/证据、完成需要人的确认；与终端读取同一套真实卡片和 pi 会话。关闭桌面及其所拥有的主会话时，受管执行停止。

> 2026-10-02 用户给出关键需求三件：**可视化**（队列/回执/证据看得见，对应 M3-02 只读看板为核心卖点）、**快速稳定**（启动/刷新响应与故障退出进选型验证标准）、**与 CLI 同一后端**（纯壳定案的重申，零第二状态）。详细需求持续对齐、逐步细化，不在此刻定死。

不要求桌面首版复刻所有终端装饰。必需确认不能因为 UI 不支持而默认同意；不支持的交互明确说明和阻止相关危险路径。

## 开工条件

M2 核心终端能力和卡片契约稳定；可以没有启用 worktree/历史检索等条件项。明确“桌面拥有哪个 pi 会话/进程”及双窗口的只读/接管规则。

先读锁版 `docs/rpc.md` 与 `docs/rpc-extension-ui.md`，查看实际 RpcClient/类型；不要拿最新网页接口直接套旧安装件。官方 RPC 区分命令接收、运行事件与结束；这些都不能直接等于 PAO 的验收通过。[E5/E10]

## 复用与选型原则

复用 pi RPC/RpcClient、M1/M2 队列与文件解析、既有配置和身份校验。壳仅调用现成 PAO 操作，不通过界面直接改卡 frontmatter。

> 2026-10-02 盘点＋用户澄清：Herdr 已装（`Programs/Herdr/bin/herdr.exe`＋ConPTY），agent 探测清单 29 个含 pi 原生支持（也认 hermes），但**用户已弃用 Herdr**（同日明确「现在不用了」；早前「点开动画还是 pi」事件＝用户在 Herdr 点 pi 条目，跑的是上游 pi 非 pao）。处置：Herdr 不作直接复用候选，仅保留其命名管道单向状态上报（JSON＋状态枚举＋seq）作壳↔本体观察通道的**协议参照**；桌面壳走自建轻壳，可抄的三样＝协议（Herdr）、交互范式（ZCode Desktop 体验参照）、框架模板（Electron/Tauri 成熟样板）。上游 pi 自身无桌面包（fork packages 核实无 desktop）。

具体桌面框架当前附件没有定案。本计划不预装某框架：优先检查本机已熟悉、能复用的最小壳；只对最多两个候选做同一功能验证，按 Windows 安装/启动、子进程、中文路径、文件打开、故障退出与维护依赖选定。无需引入服务端和登录系统。

只锁所选框架与桥接依赖；不因 UI 选型把 pi 源码内嵌或 fork。壳依赖构建工具的事实与“另有第二内核”区分，但二者都不能无依据扩大。

## 任务与顺序

### M3-01｜最小桌面验证与 RPC 能力清单

做最小窗口：启动用户指定的锁版 pi、发一句真实请求、显示流式结果、取消并正常退出。核对安装路径/版本与中文空格路径。

记录命令、事件、扩展对话框、卡片读取与模型设置的可用映射；传输完成、agent 结束、卡验收三个层次分开。先有这张清单再写大界面。

**交付**：桌面框架选择记录、最小真机样例、锁版接口检查。**不做**菜单动画、主题市场或高级看板。

### M3-02｜只读看板与项目切换

直接读 `.pao/` 卡片，复用 `/队列` 分组/排序/依赖/协作/待验证/警告规则。桌面不保存第二份卡片状态；解析坏文件、目录暂不可读要显示异常，不能把它们解释成“队列空”。

跨项目通过既定项目清单聚合。任意点击路径先解析其归属，不按两个项目相同卡号合并。基础刷新可用文件变化通知加手动刷新；通知丢失后重读文件恢复，不以事件流作为正本。

点击回执和证据打开实际文件；大文件不整页自动塞进模型。UI 可以缓存展示，但重新读取正本后应一致。

**交付**：项目切换、只读队列/详情、证据定位与异常展示。**前置**：01。

### M3-03｜对话、派发、取消与人工确认

用户输入经当前 pi 会话；派卡和队列修改走同一 PAO owner 入口，不在桌面再写一套调度逻辑。操作带关联标识，响应丢失先查状态，不重复发送一个会写项目的请求。

接入暂停发新活/取消当前任务的既有语义，显示“正在停止”与“已停止”区别，不能按钮一按就假报取消完成。高风险操作的确认要正确回送，关掉对话框、超时或断线不能默认授权。

扩展的终端专用 UI 可能无法原样用于 RPC；需按官方支持面处理。核心确认能力缺失时阻断功能，纯显示件可明确降级。[E10]

**交付**：真实对话、派发、取消、确认与重复操作防护。**前置**：02。

### M3-04｜配置与多窗口归属

桌面只编辑既有允许编辑的配置：项目入口、模型菜单/档位、已批准工具等；敏感值不展示在日志或截图。配置校验失败保留原值，设置不静默覆盖全局 settings/models。

一个目标会话只有一个写控制方。第二窗口默认只读；显式接管前让原 owner 退出或按已有规则交接。UI 断线、进程仍活与进程死亡要区分，不能每次重连都另开一个 worker 树。

壳关闭时停止自己拥有的 pi/PAO 子进程；不得杀用户另开终端的独立 pi。关闭但继续后台运行不作为默认功能，以免违背无常驻纪律。

**交付**：配置读写与恢复、多窗口/接管边界、可诊断的连接状态。**前置**：03。

### M3-05｜桌面故障与真实日常验收

复跑取消、强退、丢连接、重复响应、慢输出、坏卡片、权限确认、项目切换与日志展开。使用相同任务在终端/桌面各做一次，核对相同卡片状态和执行结果，而非只核对 UI 截图。

新增的壳延迟/资源开销单列，模型 token 不应因 UI 无故增加一份；确有新的对话/审查则计入实际调用。保存 Windows 构建/启动与可复现日志。

**交付**：桌面验收报告、终端对照、已知 UI 降级清单。

### M3-06｜交付与条件升级

发布能独立启动的桌面入口，说明如何选择已安装锁版 pi、如何退出/取消、证据在哪、如何退回终端。桌面升级与 pi 锁版升级分开，不强制同时更换内核。

条件升级：部门专场仅在中继聊确有重复往返问题时加入；实时 JSONL 活动流只作可丢弃展示，不成为恢复正本。基础桌面没稳定前不做终端完全复刻、标签市场、多用户/租户或云端同步。

**交付**：构建产物/启动说明、版本兼容说明、回退指南和当前未支持项。

## 验收

| 编号 | 场景 | 通过条件 |
|---|---|---|
| G3-01 | 桌面启动指定锁版 pi | 真正启动同一内核，版本可见，路径可靠；未内嵌第二套会话/调度 |
| G3-02 | 命令 accepted、事件结束、卡验收不同时到达 | UI 不误报已交付；知道请求已接收与任务已完成不同 |
| G3-03 | 终端/桌面读同卡、异常卡文件与目录 | 状态/排序/依赖一致；坏数据明示，不假空队列 |
| G3-04 | 重复点击、响应丢失、重连 | 不重复建卡、派发或计费；先核现实状态，不盲重发 |
| G3-05 | 取消、关窗、杀桌面、pi 异常退出 | 拥有的任务按 M1/M2 纪律停止，其他独立会话不误杀；下次人工盘点 |
| G3-06 | 扩展确认、超时、取消对话框、不支持 UI | 不默认授权；核心确认可用，否则明确阻断相关操作 |
| G3-07 | 双窗口同项目/同会话、接管与项目切换 | 只有一个写 owner；不串卡、热上下文、权限或模型设置 |
| G3-08 | 配置错误、凭证、证据路径、中文空格路径 | 错误可恢复；不泄密；文件真实可达，不能任意借文件打开扩大执行权限 |
| G3-09 | 同一类真实任务终端/桌面对照 | 交付同等可验，额外开销被记录；停用桌面仍能继续终端使用 |

需要更强的网页/脚本隔离时按所选框架安全文档再细化；这不是授权把不可信网页开放为有本机全权限的 UI。

## 完成与回退

核心桌面任务可用、确认与停止链可靠、文件与会话唯一真相保持，终端仍独立可运行。没有上述证据，不用“窗口能打开”代替桌面完成。

出问题只回退桌面版本或关闭新增 UI 功能，保留 pi/PAO 及原卡片。不能为修界面删任务、重建知识正本或替换内核版本。可选专场/实时流没有启用，不阻塞基础桌面完成。
