# 调研：wemux（zolrath/wemux v3.2.0）

来源：用户指路 `github.com/zolrath/wemuxclone`（实名 zolrath/wemux，「后扒一下、很多可以直接抄」）。已浅克隆至 `D:\AI\workspace\wemux`（工作区外独立目录，不入任何仓）。规模：单文件 bash 757 行＋conf 样例＋man，MIT 许可。2012-2013 年代项目，机制成熟稳定。

## 1. 它是什么

多用户共享 tmux 会话：host 用自定义 socket 起 tmux server，client 三模式接入；host 可全程仲裁。核心价值不在代码量，在**十年验证过的「旁观/协同/接管」交互语义**。

## 2. 核心资产清单

### A. 客户端三接入模式（最大资产）
| 模式 | 实现 | 语义 |
|---|---|---|
| mirror | `tmux attach -r` | 只读旁观，看的就是被看者眼前的屏 |
| pair | `tmux attach` | 共享光标，共同控制同一视图 |
| rogue | `tmux new-session -t <组名> -s <组-用户名>` ＋自名窗口 | **grouped session：同一窗口世界、独立光标/独立当前窗口**——「进同一个会话世界接管，但不动主人视角」 |

### B. host 仲裁命令族（第二批资产，全部＝遍历 `list-clients`＋`switch-client`）
- `summon`／`summon_all`：把（镜像中/全部）观察者拉到 host 当前视角——强制同步现场
- `setmirrored`：全员收只读——**收回控制权**
- `togglemirrored`：mirror↔pair 全员翻转
- `kick`：踢 SSH 用户＋清掉他的 rogue 会话（sudo lsof 找 sshd PID＋kill-session 通配）
- `users`：在线名单＋模式标记 `name[m]`（[m]=只读）
- `announce`：attach/detach 广播（tmux display-message）
- `stop`：停 server＋删 socket 文件

### C. 工程与安全细节
- 身份取 `whoami` 而非 `$USER`（防环境变量伪造成 host）＋host_list/host_groups 白名单双通道
- socket `chmod 1777`（sticky bit）开放 client 连接
- 嵌套防护：`$TMUX` 变量检测＋嵌套白名单命令表（summon/users 等允许在会话内跑）
- server 名清洗（空格/下划线→横杠、剔非字母数字、小写）＋`~/.wemux_last_server` 记忆
- `smart_reattach` 智能默认：有 rogue 续 rogue→配置默认模式→mirror 兜底

## 3. 映射到 PAO

| wemux 概念 | PAO 现有对应 | 抄法 |
|---|---|---|
| mirror 只读旁观 | worker JSONL read-model 投影（桌面看板/全景） | 语义已有，wemux 印证口径：旁观＝看原件而非摘要 |
| pair 受控共写 | 控制入口写请求（③五态实施中） | 边界设计可抄：写入是**受控动作**，不是自由键入 |
| rogue 独立接管 | P3 需求原词「显式接管」 | **抄语义：接管＝独立视角进同一会话世界，不夺主控视图**——解形态争议 |
| setmirrored | 无（可新增「收权」） | 控制入口加收权动作：接管完锁回只读 |
| summon | 两级钻取第二级（卡→跳会话现场，缺数据键待补） | 语义同名：把用户拉到卡点现场；fork 补会话 id 后一并接 |
| users＋[m] 标记 | 看板 owner 列 | 轻量在场＋模式标记范式 |
| announce | B 档静默提醒 toast（已有） | 已对齐，无需动 |
| kick | pao_终止卡/终止 worker | 已有等价物，不重复建 |

## 4. 「直接抄」的边界（关键判定）

- **现场硬约束：fork 跑在 Windows（Git Bash），tmux 原生不存在**（仅 WSL 内有）——wemux 脚本本身在现场不可直接跑，「直接抄」的正确姿势是**抄交互蓝本（命令面＋模式语义＋host 仲裁规则），TypeScript 实现**（合 fork 路线定案「定制一律 TS」）。
- 具体三件（后续批次，不阻塞在跑的③）：
  1. 桌面「会话观察与接管」命令面照 wemux 抄并中文化：mirror/pair/rogue/summon/users/kick → 旁观/协同/接管/拉我看现场/在线名单/终止。
  2. 「显式接管」定为 rogue 语义（独立视角，主控视图不受扰）；配 setmirrored 式收权。
  3. summon 语义接两级钻取第二级。
- MIT 许可：若未来出服务器/SSH 部署形态，wemux 脚本可原样用（保留署名）。
- 落面归属（AppView 全局面 vs 扩展视图会话面）待「双看板面归一」一并拍板，先不单定。

## 5. 待用户拍板
