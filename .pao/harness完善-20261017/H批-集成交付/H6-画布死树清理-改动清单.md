## 必须让用户先知道的代价

- 删除后 **T23 的「节点耗时」一项在没有新增界面出口之前无法满足**（计划 §11.3 T23 原文把
  「耗时」列为通过条件之一，`workflow-cards` 视图当前没有渲染任何耗时字段：2026-10-17
  grep `workflow-cards/*` 对 `耗时|duration` 零命中）。**这是产品口径问题，不是代码问题**：
  要么删除画布时接受 T23「耗时」改为未验，要么先给卡片视图补一个耗时出口再删。
- `recipe-canvas-editor` / `workflow-editor` 是配方编辑能力，删除后配方只能改文件（终端/命令），
  与计划 §7.4 T21「日常不读写 JSON」存在张力——若将来要恢复配方编辑 UI，得从 git 历史取回。
- 仓库是**目标 Windows 机器上的非 git 工作区改动不可回落**的项目：这些文件有 git 历史（HEAD 里在），
  删除本身可回滚（`git checkout HEAD -- apps/desktop/src/features/canvas`），但恢复后要重新接视图。
