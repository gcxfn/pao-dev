日期：2026-10-18。依据：[执行计划 §10.5](../../../plans/未完成/2026-10-17-Harness完善与工作台迭代执行计划.md)。用户定案：Todo 清单和当前部门状态放右侧常驻，参考 ZCode 右侧摘要布局；删除左侧「工作流」「工作看板」两个入口，保留会话和定时任务。用户起初要求用 DeepSeek high 子代理，工具明确不支持该模型后改为授权主代理直接实现。

## 改了什么

新增右侧常驻状态区，分上下两段：上半「待办清单」显示当前会话最近一次写下的 Todo 与当前 PAO 计划的步骤卡，下半「当前部门」按项目与主控会话过滤显示部门任务，已结束部门折叠在展开区；读取失败、空数据、清单被清空、切会话都有对应显示，不再拿上一次结果冒充当前。右侧同时提供「计划详情 ↗」和「全部任务 ↗」两个入口，打开的是原有的工作流编辑页与四列部门看板，会话跳转、验收、意见等既有能力不变。

打开文件或终端时，工具面板排在同一列的右侧状态区下方，状态区保留不消失。为此把右侧坞从 `App.tsx` 抽成独立组件 `apps/desktop/src/app/task-status-dock.tsx`，`App.tsx` 由本批改动前的 1510 行降到 1440 行（eslint 实测，配置上限 1447，`desktop/eslint.config.mjs:94`），此前工作副本遗留的行数超限一并关闭。

左栏首轮只留「会话」和「定时任务」，删掉「工作流画布」「工作看板」两个导航项及其图标引用，旧持久导航值、扩展注册、任务与看板数据都保留、没有新增替代入口。**此后用户反馈这两个入口不该删（原话「我哪里要求删掉了，加回去」），已在第五轮把 `sidebar-canvas`（工作流）和 `sidebar-workboard`（工作看板）加回 `features/threads/sidebar.tsx`，现左栏共四个导航项**。第五轮尚未单独成节记录，证据与待补事项见[交接-右侧状态区方案B-20261019.md](../交接-右侧状态区方案B-20261019.md) §九。

量测中发现并修掉三处由布局变更带出的问题：右侧坞的分隔线原本用 `border-left`，占用 1px 把工作台挤成 359 宽，改为等宽内阴影；工作台宽度手柄原本拿「父元素的父元素」当容器算上限，坞嵌进来后容器变成坞自身，拖一次就塌到 40px，改为向上找 `.main` 再算；部门看板的内层选中态只在收到非空分组时同步，右侧「全部任务」传空时退不回四列总览，改为无条件同步。

第二轮的窄窗加固给了收起按钮，但 900px 一类窄窗里侧栏 220px 与右侧坞 320px 同时常驻，主区只剩 360px，输入框挤到 299px、占位文字换行成两行。用户在看过三档实测后决定按建议继续做：**≤980px 视口下右侧坞默认收起**，靠展开按钮找回。

1. 新增 `apps/desktop/src/ui/narrow-viewport.ts`：导出 `NARROW_VIEWPORT_WIDTH = 980` 与 `useNarrowViewport()`。判定直接读 `window.innerWidth` 并用 `useSyncExternalStore` 订阅 `resize`（不用媒体查询：Playwright 的 `setViewportSize` 下 `innerWidth` 一定跟着变，媒体查询在模拟视口里未必可靠）。这个常量成为三处窄窗阈值的唯一来源。
2. 改写 `features/task-status/use-task-status-collapsed.ts`：原 hook 返回布尔偏好，新增窄窗参与判定，改为导出 `useTaskStatusDockCollapse(toolsOpen)` → `{ collapsed, collapse, expand }`。判定式 `collapsed = !toolsOpen && (collapsedByUser || (narrow && !expandedInNarrow))`。语义分三层：窄窗默认收起是默认值、不写偏好；用户在窄窗里点开只在本次运行保持（不把保护永久关掉）；用户手动收起是明确的窗口级偏好，会记住，宽窗也照做。打开工具面板时一律展开（工具期间不渲染收起按钮）。
3. `workbench-resize-handle.tsx` 删掉自己的 `NARROW_VIEWPORT = 980`，改 import `NARROW_VIEWPORT_WIDTH`，避免第三份 980。
4. `TaskStatusDock` 只改两行接线：`const { collapsed, collapse, expand } = useTaskStatusDockCollapse(toolsOpen)`，`onCollapse={toolsOpen ? undefined : collapse}`、`onClick={expand}`。**`App.tsx` 仍零改动**（1440 行 / 上限 1447）。
5. `d4-sidebar-draft.spec.ts` 原「窄窗口里右侧状态栏可以收起」用例改写为「窄窗口里右侧状态栏默认收起，展开能看、收起能记住」：宽窗 360 → 900 档 rail 不存在、展开按钮可见 → 点开得 320 且不写 `"true"` → 再收起主区变宽 200px 以上且写入 `"true"` → 刷新后仍收起 → 再展开写 `"false"` → 回 1440 仍 360。
6. 顺带修掉测试辅助的一处偶发：`tests/helpers/electron-app.ts` 的 `reloadDesktopRenderer` 原来只重试一次 `reload`，组合跑时被拦下的导航偶尔连续中止两次。改为同一条件下限次重试（3 次），其它错误照旧上抛。
