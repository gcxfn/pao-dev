### 遗留②：pre-check 口径与 payload 对齐

`src/pao/desktop/index.ts` 原 `:88` 对所有动作都要求 `node` 且 `round` 匹配，现在改为：

```ts
const staleError = () => new Error("实例/卡目录/节点/轮次已变化，请刷新");
if (params.name !== flow.工作流 || params.cards_dir !== flow.卡目录) throw staleError();
// confirm 必须锁定节点与轮次；pause/resume 由内核按当前停因定位，只有调用方显式传入
// node/round 时才核对——否则调用方漏传会得到「已变化，请刷新」这种误导性错误。
if (action === "confirm" || params.node !== undefined || params.round !== undefined) {
	if (!node || params.round !== node.轮次) throw staleError();
}
```

即 pause/resume 不再因漏传 node/round 被误判为「已变化」；confirm 仍强制锁节点与轮次。
