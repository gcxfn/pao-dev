# I5 接续基线

本目录保存 2026-10-29 在 I1/I2/I3/I5 开始改产品代码前捕获的源码状态。

- **`HEAD.tar` 与 `head/`**：Git HEAD `6fee6ee9d7914a04803a407ecd303ec563b542b2` 的完整树。
- **`current/`**：相关目录当时的工作副本，包含未提交已跟踪改动与相关未跟踪文件。
- **`worktree.diff`**：相关路径相对 HEAD 的已跟踪差异；未跟踪原件直接保存在 `current/`。
- **`status.txt`**：相关路径的状态清单。
- **`current-sha256.txt`、`HEAD.tar.sha256`**：快照校验值。
- **`G2-baseline.json`**：固定 G2 计数定义；测量结果尚待从本快照实际运行产生。

回放时应在 `current/` 的副本上构建或提供依赖，不直接写入该目录；不得用后来的工作区冒充本快照。
