**端到端实证**（对抗审查最重项）：worker 子进程用 `--mode json -p --no-session` 拉起——该模式是否发 session_shutdown 静态追到 SessionManager.inMemory 为止,直接真跑实证：`PAO_ROLE=worker node src/cli.ts --mode json -p --no-session "只回复两个字:收到"` → 账本落行 `{"角色":"worker","input":4027,"output":3,"cacheRead":64,"cost":0.00566764,"turns":1,"缺用量轮次":0}`。「全角色对账」实证成立非纸面。
