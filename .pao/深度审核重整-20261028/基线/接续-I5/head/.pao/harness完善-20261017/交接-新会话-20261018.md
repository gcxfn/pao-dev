## 四、跑起来之前必读的本机陷阱

| 陷阱 | 症状 | 处置 |
|---|---|---|
| **`ELECTRON_RUN_AS_NODE=1`**（DSH 宿主注入，进程级） | 一批用例全在 `helpers\electron-app.ts` 的 `launchDesktop` 失败、报 `bad option: --remote-debugging-port=0` | 跑任何 Electron 命令前 `Remove-Item Env:\ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue`，**同一进程内** |
| **必须先 build 再跑 Playwright** | 改了 `src/` 却对着旧 `out/` 跑，得到假绿或假红 | `pnpm --filter @pi-gui/desktop run build` 成功后再跑；只改 `tests/` 下 spec 才不用重建 |
| **shell 管道回写源码会毁中文** | `Get-Content -Raw \| Set-Content -Encoding utf8` 让 UTF-8 中文变乱码（读取侧按 GBK 解码） | 源码/文档一律用 `edit`/`write` 工具；改完做字节级 FFFD 校验 |
| **prettier CLI 会把 CRLF 判成不合规** | `node node_modules/prettier/bin/prettier.cjs --check <file>` 对被 git 改过行尾的文件报 warn | 用 `prettier --write` 落盘再 `--check`；不要手写批量替换改格式 |
| **Playwright 每次跑先清 `outputDir`** | 失败 trace/png 下次就没了 | 失败产物当场备份到 `.pao/harness完善-20261017/...` |
