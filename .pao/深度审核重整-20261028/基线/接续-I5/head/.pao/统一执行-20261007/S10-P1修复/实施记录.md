## 根因（比波审链多挖一层）

**关键发现：任务设想的「delivery.ts 改从 todo/summary.ts 取」不足以断链。** S9-todo 建的 summary.ts 公开面是**运行时值 re-export**（`export { scanTodoState … } from "./index.ts"`），ESM re-export 触发被引模块求值——切了 delivery 后链只是变成 `delivery.js → todo/summary.js → todo/index.js → pi-tui`，同败。`summary.ts` 另一条腿 `from "../ui/todo-summary.ts"` 也经其 `import { renderTodoList } from "../todo/index.ts"` 回到同一断点。纯函数面「无 TUI 依赖」只对导出表面成立，对模块图不成立。
