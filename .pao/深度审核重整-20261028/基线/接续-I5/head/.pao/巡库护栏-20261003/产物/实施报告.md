## 设计取舍

### 公共面（全中文标识符，随 patrol/ 新模块惯例）

- `审查Shell命令(命令: string, 配置: 护栏配置): 护栏结论` —— 主判定；任一 token 违规整条拒（fail-closed）。
- `护栏配置`：`工作区`（必填，机械上必须是绝对路径，否则「配置无效」拒）、`已知变量`（变量名→展开值，大小写不敏感，支持中文名）、`系统目录`（按键整表覆写缺省黑名单）。
- `护栏结论`：`放行` ＋ 拒绝时的 `类型`（命令替换／未知变量／敏感文件／系统目录／工作区外／无法确定／配置无效）与 `说明`（含命中的原始 token，可直接写进回执与巡库卡）。
- `系统目录表` ＋ `缺省系统目录表`：三张子表（win32前缀／win32段／posix段），规格要求的「可传参数的缺省表」。

### 路径提取的边界（判定集是保守下界，不是完整路径识别）

1. **切词**：按空白与 shell 操作符（`| & < > ; ( )`）切分，剥成对引号（引号内容并入当前词，与 bash 拼接语义一致，带空格的引号路径不散架）。不做引号内转义解析——含转义的花活落在变量残留检查处自然 fail-closed。
2. **哪些词按路径判定**：重定向目标（`>`/`>>`/`<`/`2>` 后第一个词，无论长相）必判；含 `/`、`\`、盘符、`~` 的词必判；裸词只在命中敏感文件名（`.env`/`.env.*`）时判——这条拦住 `cat .env` 这类无分隔符读写；其余裸词（`echo hello`、`git commit`、`-m` 旗标）不判，误伤面最小。已知缺口：`--flag=~/x` 这类波浪号不在词首的旗标内嵌路径按相对路径解析落工作区内放行（bash 也只在赋值场景展开它，机械筛不追）。
3. **解析与包含判定**：双分隔符归一切段（collab/index.ts 同款归一思路，但两侧不同源，一律再走小写归一）；POSIX 绝对路径挂到工作区盘符下（与 win32 resolve 语义一致）；相对路径从工作区起算，`..` 按段折叠且不越过盘符根。包含判定是**段级前缀比较**而非字符串前缀——`C:\Windows` 不会误吞 `C:\WindowsFoo`。等于工作区本身的路径放行（护栏判落点，不判意图，`rm -rf 工作区` 挡不住，属机械筛边界）。
4. **变量展开**：`%VAR%`、`${VAR}`、`$VAR` 在切词前整串展开（表内值含空白时补引号，防止 `C:\Users\John Doe` 被切散丢锚点）；表外变量、展开后残留的 `$`（`$5`、`$?`、`$@` 等）一律拒。`~`/`~/` 视为引用 `已知变量.HOME`；`~user` 形式拒为「无法确定」。
5. **拒的顺序**：敏感文件 → 系统目录 → 工作区包含。顺序决定拒绝类型：工作区内的 `.env` 得「敏感文件」而非放行，`/etc/passwd` 得「系统目录」而非笼统的「工作区外」，回执可读性更好。
6. **POSIX 系统目录只对「词首为 `/` 或 `\` 的绝对路径」的根段生效**：工作区相对路径 `bin/foo`、`node_modules/.bin/x` 不误伤；`/bin/foo` 必拒。Windows 段黑名单（system32）对盘符绝对路径的任意段生效（WINDIR 挪盘时兜底）。
7. **配置无效也是拒**：工作区为空或机械上不是绝对路径（无盘符、非 UNC、非根起头）→「配置无效」拒——纯函数无 cwd 可依，调用方必须传绝对路径。

### 诚实声明：机械筛挡不住什么（已写进模块头注释）

第一道防线是配方与工具列表（无人值守 worker 拿到什么工具、提示词怎么约束），本护栏是第二道机械防线，不提供进程级隔离。已知绕过面：

- **嵌套引号里的完整子命令串**：`bash -c 'cat /etc/passwd'` 的内层串不按子命令重新切词（内层 token 含空格＋分隔符时按相对路径解析会漏放）。接线上应保证无人值守 worker 拿不到任意 shell 类工具。
- **管道交外部进程落盘**：`something | remote-upload` 的真实落点不在命令 token 里。
- **工作区内的符号链接/junction 指向外部**：纯函数不查文件系统，判不了真值；如需兜底由接线层加真值校验。
- **shell 求值花活与编码变体**（`$'...'`、八进制转义、URL 编码等）：不在机械筛射程内。
- **规格字面口径的边界**：`notes.env`、`env.example`、`.envrc` 不在 `.env`/`.env.*` 黑名单内（按规格不外扩）；`/dev/null` 会被 POSIX 清单误拒（宁紧勿松，接线上可覆写 `posix段` 放行）；`rm -rf <工作区本身>` 放行（判落点不判意图）。

测试覆盖对照（27 例，≥15 达标）：

- 放行：工作区相对/普通命令；绝对路径 `/` `\` 双写法；大小写不敏感＋双分隔符归一；`..` 出去再回来落点仍在工作区内；工作区内重定向（`>`、`>>`）；已知变量指向工作区内；URL 与含 `.env` 字样的普通参数不误伤（`notes.env`、`env.example` 放行）；纯函数不碰文件系统（不存在的路径照判）。
- 拒·工作区外：Windows 盘符（同盘异目录＋另一盘符）；POSIX 风格 `/`、`\` 双写法；`../` 逐级逃逸；重定向目标逃逸（含 `2>`）；UNC `\\server\share`；引号内带空格路径。
- 拒·敏感文件：`.env` 任意目录（含工作区内绝对路径、重定向目标）；`.env.local`、`.env.production` 变体。
- 拒·系统目录：Win（C:\Windows\System32、D:\System32 段规则、Program Files）；POSIX（/etc/passwd、/usr/bin）；黑名单表可传参覆写（自定义 win32前缀 生效＋缺省键整表替换、win32段 清空后类型变化、未传键保持缺省）。
- 拒·无法机械确定：未知变量 `$X`、`%UNSET%`（说明含变量名）；展开后残留 `$`（`$5`）；命令替换 `$()`、反引号、进程替换 `<()`；`~` 展开判定（有 HOME → 工作区外拒；无 HOME → 未知变量拒；`~root` → 无法确定）；`$HOME`、`%USERPROFILE%`、`%TEMP%` 展开后落主目录拒；粘连 `..` 段（`--output=../x`）。
- 配置：工作区非绝对路径（相对/空）→ 配置无效拒；空/纯空白命令放行。
