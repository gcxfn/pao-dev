# PAO 易用性优化执行报告

完成日期：2026-10-11。用户于 2026-10-10 回复“执行”，本轮按计划完成。范围限定为 PAO fork 自有内核、TUI 和桌面端，不修改 pi 上游本体、正式 PAO_HOME、认证配置、生产进程，不执行提交、推送或发布。

## 结论

界面易用性优先的阶段 1—4 已完成。桌面端新增的刷新、对象提示、操作入口、窄窗口布局和详情收起均通过真实 Electron 验证；TUI 的面板搜索、滚动、设置异常提示、工作流引导和新版实例查看通过组件测试与隔离 Windows ConPTY 验证；内核的查询复用、Git 查询复用和查库取消通过定向测试、真实本地 HTTP/Git 夹具和性能测量。

## 已修改

- **桌面端**：任务卡看板增加 30 秒静默刷新、读取时间、失败保留旧内容和重试入口；卡片与配方提供可见“更多操作”，选择卡片入口、Escape 关闭、焦点返回和复制失败提示；画布刷新同步控制区与节点详情，显示读取时间、失败原因和按钮不可用原因，阻止旧请求覆盖新节点；画布和看板详情支持收起恢复，窄窗口保留主要操作空间。
- **TUI**：全景页支持新版 v2 工作流、同名实例按身份选择和损坏实例的明确错误；面板支持搜索、滚动、无结果后退格恢复及 12/16/24 行 resize；设置页区分未配置、关闭、非法 JSON、字段错误和不可读；工作流命令按操作、配方、实例、节点提供选择引导。
- **内核**：一次桌面读取复用卡路径和 worker 会话目录索引；一次结果聚合按真实工作目录、基线和完整 Git 参数复用查询 Promise；嵌入请求的请求头和正文读取支持取消与超时并清理监听，同一调用内相同查询和配置复用嵌入结果。
- **测试**：补充桌面、TUI、内核回归测试以及隔离性能、HTTP、Git、ConPTY 验证脚本；测试数据和临时原始输出保存在本目录和 `临时文件夹/PAO易用性优化-20261010/`。
