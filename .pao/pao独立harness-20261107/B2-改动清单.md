## 5. 歧义 / 裁决点（需用户知悉）

1. **`@earendil-works/gondolin*` 保留外部名**：npm 上有真包，不属于内部内核；例子 `examples/extensions/gondolin/` 与 `npm-audit.mjs` 的引用按外部依赖保留。
2. **`@pi-app/video` 未映射**：任务书只覆盖 `@earendil-works` 与 `@pi-gui`，该 scope 不同，未动。
3. **`virtual-modules.ts` 未为 `@earendil-works/*` 保留旧别名**：判断为改名即断点，扩展需升级到 `@pao/*`；`@mariozechner/*` 上游兼容别名保留。
4. **`packages/session-backends/sqlite-node/`**：只剩 `dist/` + `node_modules/`，无 package.json、非 workspace 成员，属上游已移除包的构建残留，未触碰；可另立清理。
5. **`tsconfig.json` 的 `@pao/agent-old`**：改名前就指向不存在路径，属上游遗留 stale 项，保留未删。
6. **`install-lock/package-lock.json` 已整体重生成**（而非局部改名）：生成器是权威产物，重生成后内部包全部落成 `node_modules/@pao/*`。
7. **`opencode-go.ts` 属改名之外的构建修复**：上游模型目录再生出 `gemini-4-argon`（api `google-generative-ai`），不改无法过 build；已按最小改动补分支并在 generate-models 后验证。
8. **不改名项按边界保留**：物理目录名（`packages/pi-sdk-driver/` 等）、导出符号（`getPiUserAgent`）、`piConfig` 键、`docs/`、`CHANGELOG.md`、`archive/`、README 品牌、`~/.pi`、语义 `.pi` fixture、`PAO/.pi/extensions/*`（上游 pi 目录）、上游 GitHub URL/组织名（`earendil-works/pi` 仓库引用、issue 编号注释、schema URL）。
