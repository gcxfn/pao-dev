## 待判定清单与后续建议

**留给 T08/T09 实机再验（core 8 条 + 平台族根因定位）**：

1. **worker 崩溃（0xC0000142）**：全套 60 分钟直跑在本机不可靠。建议 T08 实机分段跑（按 spec 分批）或清理后重试；如需全套口径，先解决长跑资源累积（怀疑桌面堆/句柄泄漏，可对比干净重启后的短套）。
2. **devNull 根因修复建议**：git-review 的 `readPatch` 不校验 git stderr/退出码语义，Windows 上静默产出空 patch+complete（掩盖差异，属可用性缺陷）。建议改用临时空文件替代 `os.devNull`，或对 `Could not access` 显式失败。此修复可同时清零 unit 3 条 + core review/diff 族 2–3 条。
3. **chord/扩展视图族（core 8 条平台失败）**：需实机定位 chord 事件桥在 Windows 上的断点（iframe 键盘焦点/事件序列化/shell.openExternal 记录）。
4. **symlink 权限**：本机启用 Windows 开发者模式（或以管理员跑）即可清零 unit 6 条，属环境处置而非代码修改。
5. **PAO_HOME**：driver 测试设施应自设隔离 PAO_HOME（已验证设后全绿），可作为测试设施小修。
6. **待判定 8 条**（core #2/#3/#21/#22/#24/#27/#28/#29）：各自缺一项实机证据（见明细表右列），建议在干净环境单跑并抓 DOM/lease/进程树后归位。
7. **唯一产品失败**（--surface-hover）：一行级修复，建议随当前未提交批一起处理。
