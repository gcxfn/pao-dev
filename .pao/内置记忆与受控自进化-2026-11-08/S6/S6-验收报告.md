# S6 成果版本、保存与按需复用

日期：2026-11-10。阶段状态：S6-01—11 实现完成；S6-11 验收证据已收集（内核定向 + 真实 Electron + Windows 发行物），S7 待启动。

## 实现结果

| 范围 | 行为 |
|---|---|
| S6-01—03 成果登记 | `registerArtifact` 登记用途/输入输出/条件（缺省存 `unknown`），Git 版本记 repo+commit+path，非 Git/未提交写 `<home>/memory/artifacts/<id>/<version>/` 受管副本 |
| S6-04 查重与重放 | Git 按 repo+commit+path 复用版本行；受管按大小+字节复用 versionId；`registrationKey` 重放只补迟到 usageRefs，不产生重复版本 |
| S6-05 版本链与回执 | `artifact_versions` 记 `parentVersionId`/`originTaskId`/`sourceIds`/`receiptRef`/`usageRefs`；失败回执如实登记，不回写历史验证 |
| S6-06 成果检索 | 独立 `artifact_fts`（trigram），索引 name+purpose+inputs+outputs+conditions+toolName；命中只回 artifactId+versionId+摘要，正文走 `resolveArtifactVersion` |
| S6-07 接续候选 | `readTaskContinuation` 尾部按 projectId 返回 ≤10 条 `artifactCandidates`，`renderBackground` 只读渲染前 3 条并标条件差异与可回读性 |
| S6-08 复用入口 | 只读工具 `pao_memory_resolve_artifact` 回读版本内容与条件；复用仍经既有 write/edit/bash，受 `MEMORY_FRESHNESS_GUARDED_TOOLS` 守卫 |
| S6-09 记忆页成果区 | 列表+详情七段：用途条件/版本选择器（seq·来源任务·验证·可回读）/内容预览/来源/验证回执/使用记录/复用说明；「打开当前文件」仅 Git 版本 |
| S6-10 删除 | `previewArtifactDeletion`/`deleteArtifact`：仍被引用的版本与受管文件保留；`purgeManaged` 才物理清除；记忆删除先 `unlinkArtifactRefsForMemories` |
| S6-11 不可达如实 | 仓移动、commit 不可达、受管副本缺失、源删除、复用失败均返回 unavailable/如实登记，不报虚假可用、不改写历史回执 |

## 使用边界

- 成果检索只索引元信息+工具名，不索引版本正文；正文按需走 `resolveArtifactVersion`。
- 接续候选 `available` 探测按登记定位存在性（Git 仓根/受管目录），commit 实际可达性以 `resolveArtifactVersion` 为准——后者如实返回 unavailable。
- 「在当前任务复用」面板只展示版本与条件差异，复用动作仍走既有任务入口与文件/执行工具授权。
- 跨项目成果只作参考，条件未知时提示先核对，不直接当约束。
