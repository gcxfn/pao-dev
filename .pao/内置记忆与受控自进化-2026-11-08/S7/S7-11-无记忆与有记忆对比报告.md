## 不占优数值与取舍（如实保留）

- **有记忆一遍前台 input 多 ~430 token**（召回块+记忆正文）。代价固定存在；换来免重新解释和正确复述，本任务下值得。
- **有记忆一遍后台提炼 input 多 ~1200 token**：提炼 prompt 需带全部候选记忆，库内容越多提炼越贵。这是持续成本，不是一次性。
- **召回不完美**：3 条预置只召回 1 条（top-3 按当前 query 选条）。`owner_token`/`acquireSessionControl` 两条与本轮提问相关性弱未被注入——预置「正确历史」不等于全部被看见，收益取决于检索命中。
- **费用字段 unknown**：`magpie/group/deepseek` 返回的 usage 只有 token，没有 cost.total；比较只能按 token 量，不能换算钱。

## 结论

同一任务、同一模型设置下：预置正确历史使模型 3/3 免重新解释且正确复述已定方案；空记忆则 3/3 必须请用户重述。代价是前台输入 +34% token 与后台提炼增量费用；召回命中率限制收益上限。样本 3+3，趋势一致但不足以证明确定收益，结论限于本冻结任务与该模型。
