## 逐项缺陷复核

### F15（Electron 不可执行）→ 已修

- **备份**：`db.serialize()` 换成 `store.db.exec(vacuumIntoSql(snapshotPath))`（`VACUUM INTO`，单引号 `''` 转义）。输出非 WAL 一致性主库镜像，段行先读、快照后取，与 serialize 同序保证一致性（backup.ts:219-221）。
- **恢复**：删掉「deserialize→内存库→serialize→写盘」中转，直接 `copyFileSync(snapshot → targetPaths.database)`，再 `new DatabaseSync` 置 WAL/外键（backup.ts:741-748）。
- **复验**：全文件仅剩 `exec`/`prepare`/`VACUUM INTO` 双端共有 API；无 `serialize`/`deserialize`/`db.backup`/`:memory:` 调用。Electron 37/Node 22 的 node:sqlite 只有 `exec/prepare/…`（无 serialize/deserialize/backup），VACUUM INTO 已在主控实测双端可用。**满足「Electron 上不再 TypeError」。**

### F07（恢复重定位 + 受管成果纳入备份）→ 已修

- **段重定位** `relocateArchiveSegments`（backup.ts:585-611）：按 manifest.backupPath 计算新落点，`.gz` 写 `compressed_path` 置 `original_path=NULL`，反之写 `original_path` 置 `compressed_path=NULL`。`readSourceEvents`（读 `compressedPath ?? originalPath`）在新 home 读恢复副本。
- **受管成果**：manifest 新增 `artifacts?: BackupArtifactFileEntry[]`（缺省兼容旧 manifest）；备份时 `kind='managed'` 版本复制副本到 `artifacts/<aid>/<vid>/<file>`；`restoreManagedArtifacts`（backup.ts:617-654）复制回并把 `location_json.dir` 重写新落点。`kind='git'` 不动（Git 对象由仓自身保留，符合 F07「只保留版本引用」）。
- **测试**：异地恢复后 `readSourceEvents` 从新 home 回读、段路径不含旧 home；受管成果 `resolveArtifactVersion` 返回 `available:true`、字节一致、`location.dir` 指向新 home。

### F08（恢复重放删除清正文）→ 已修

`purgeDerivedIndexes`（只清 FTS/向量）→ `purgeExcludedContent`（backup.ts:449-582）：

- **命中修订两类**：排除行 `memory_id` 非空 → 该记忆**全部修订**命中（关键——`deleteMemory` 删的是整条记忆，exclusion 带 `memory_id` 即代表整条删除，全修订命中正确，否则 D2 已删记忆正本会残留）；`isSourceGloballyExcluded` 判整体排除来源 → 其全部引用修订命中（共享保留来源不命中）。
- **全修订命中才清正本**：DELETE memories/memory_revisions/fts/vectors/usage/links/revision_links + `unlinkArtifactRefsForMemories`；部分命中保留其余修订、只清命中修订索引。
- **来源行删除**：整体排除来源 ∪ 整删记忆独占来源，守卫 `NOT EXISTS remaining links`（共享保留来源保留）。
- **task_continuations**：复用 `applyDatabasePlan` 同款 UPDATE 置 `content_available=0`。
- **归档段重写** `redactExcludedArchiveEntries`（backup.ts:661-709）：purge 后用 `isSourceGloballyExcluded`（sessionId+entryId 形态，sources 行已删不影响排除表查询）选候选——独占来源在其引用记忆整删后判整体排除；共享保留来源判 false 保留。调 `deletion.ts` 的 `rewriteSegmentFile` 按 entryId+eventType 整事件移除。未重写的计入 `limitation` 如实展示，不伪装已删。
