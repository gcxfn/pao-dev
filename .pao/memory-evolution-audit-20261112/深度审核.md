# 持久记忆与自进化关键运行链深度审核

核实日期：2026-11-12。需求与源码覆盖沿用[审核报告](审核报告.md)和四份分报告，本批补充公开业务入口、磁盘恢复、真实子进程及真实 SDK 会话的运行证据。

## 结论

**新会话的自动采集、提炼和持久化链路能够运行；跨会话后台续作、异地恢复、删除后恢复和自进化验收仍存在确定缺口。当前成果不能通过原计划的完整验收。**

六个场景均未满足所核对的完整业务预期。其中 D6 的新会话提炼成功，旧会话续作失败；D5 定位的是版本装配与验证编排缺口，命令本身按给定文件正确执行，不另算一个命令执行缺陷。问题与既有发现合并处理，不重复累计缺陷数量。

## 运行结果与处理归属

| 场景 | 实际运行与结果 | 判断与修法 |
|---|---|---|
| D1：异地恢复后的来源回读 | 从真实用户会话采集来源并建立记忆；备份后关闭连接，移走原现场，恢复至新 home。恢复返回成功、复制了一个来源段；`readMemorySource` 仍读取原 home 的绝对路径，返回 `source_missing` | 维护 F07，O07。恢复时把受管来源路径定位到恢复目标，随后从新 home 回读原文；不能只验复制数量 |
| D2：最新删除记录约束旧备份 | 先备份，再通过预览与删除入口完成删除；恢复时传入 `liveHome`，确实重放一条排除记录。恢复库的 `getMemory(includeHistory=true)` 仍返回已删除结论与修订正文 | 维护 F08，O07。沿现有删除流程完成正本、历史及受管来源清理，恢复后按 ID 与来源回读共同遵守删除结果 |
| D3：选择后冻结验收 | 登记真实磁盘技能及版本，声明问题、分类、选择改善方案，再冻结三组样例。选择把问题置为 `candidate`，冻结入口要求 `classified`，返回 `invalid_input` | 进化 E04，O10。统一选择、冻结、生成的状态职责，使既定业务顺序能够连续执行 |
| D4：零验证候选的发布门 | 经公开入口登记资源、快照、声明问题、分类、冻结完整三组样例、生成候选；提交 `caseResults=[]`。评估返回 `passed`，总用例数 0；随后成功固化版本、激活，生效版本目录可用 | 进化 E06/E08，O11。评估必须匹配冻结计划中的完整用例与实际回执；发布依赖完整验收和固定的已验内容 |
| D5：同条件双侧执行是否使用候选 | 通过公开生成入口得到含新增验证步骤的技能候选。保持同一用例、初始文件和检查命令，仅切换 `side` 与 `candidateId`，真实执行两次 `node check.cjs`；旧版和候选均退出 1 | 进化 E07，O11。现有 command runner 按 `initialFiles` 执行，不自动装配版本资源。业务配对入口须为两侧实际加载各自版本，同时保持任务输入与判据相同；当前 E2E 由测试调用方预先替换文件，不能证明产品具备该编排 |
| D6：真实 SDK 中的跨会话后台续作 | 原会话已有持久来源和待办提炼任务，关闭原连接后新建 SDK 会话；使用生产 `registerBuiltinMemory`、真实扩展事件、模型运行时和会话文件。新会话提炼请求 1 次，作业 `done`，新结论已入库；旧作业仍为 `pending`、`attempt_count=0`、无游标 | 存储 F06，O03。从持久队列发现待处理会话，并在真实宿主空闲时消费；只恢复状态和消费当前会话的内存集合不够 |

D6 证明正常自动提炼的实际接线有效。D1/D2 证明恢复函数返回成功和索引清理不足以代表来源可用与删除保持。D4 证明完整验收缺失能贯穿候选、评估、发布和生效，而不仅是单个辅助函数的静态风险。

## 参考机制的落实判断

主要参考项目的固定版本与源码引用见[总体机制对照](审核报告.md#3-成熟项目机制借鉴)。本批按实际行为进一步判定：

- **Hindsight 的来源关联与提交复核**：来源采集、引用定位和自动入库有真实 SDK 证据；来源恢复、删除保持与跨会话续作仍有缺口。先修来源生命周期，再依赖整理结果。
- **Hermes 的后台维护与实际使用**：新会话结束可以触发提炼；持久队列尚不能保证旧会话续作。原报告确认的模型按需展开、经验整理、技能实际使用观察等缺口继续按对应任务处理。
- **Reef 的同条件对照与验证/激活分离**：候选副本、固定版本、发布和激活操作实际成立；验证内容为空仍可生效，同条件命令运行也未自动消费候选资源。需要落实完整验收与实际版本装配。
- **LobeHub 的证据与执行关联**：来源和修订详情结构存在；恢复后的已删除正文仍可读，说明管理展示还依赖底层生命周期语义。成果实际执行与费用关联沿原发现处理。

这些结论判断本项目采纳的具体机制，不要求整套移植参考项目。
