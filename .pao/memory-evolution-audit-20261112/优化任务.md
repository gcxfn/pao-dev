### 成本计量口径

确认日期：2026-11-15。本轮记忆与自进化以实际 token 用量统计成本、设置额度和结算；金额仅在有明确单价时作补充估算，不作为 token 成本已知性的依据。

- 每次实际请求记录 input、output、cacheRead、cacheWrite、totalTokens，并按请求、任务、候选和用途汇总。使用 SDK 归一化口径；缓存明细不与包含它的输入重复相加，reasoning 已包含在 output 时不再加一次。
- 请求前预留 token，完成后按实际 usage 结算；失败和取消已产生的用量照计。同一请求不重复累计。缺失实际用量标未知并保留相应预留；缺少单价不把已知 token 标未知，也不阻止 token 结算。
- 总量、每日后台额度及单次额度均使用明确的 token 单位；不凭空设置额度。复用现有账本，现有金额记录保留其单位，不把美元数值直接当成 token 配额。
- 已有 1200 token 证据可用于确认该次请求的用量；SDK 的 cost.total=0 不能证明零 token，也不影响这 1200 token 的计入。金额缺价显示为未估算。
