## E10：生成前停止条件（P2）

- `proposeCandidate` 开头（步骤 1-2 之间或资源校验后）新增检查：
  - `getResource(...).autoEvolutionEnabled === false` → 返回 `{status:"rejected", reason:"资源已停用自动进化"}`，不发请求、不占预算。
  - 本轮终止：查该 problemId 已有 validations 的 case_results_json——若任一 validation 的 holdout 组有 failed/incomplete 判定 → 拒绝再生成（保留组失败结束本轮，不回灌）。

  - 尝试计数：现有 `evolution_candidates` 行数硬上限 3 保留；no_change/duplicate/解析失败不产生行。用 job 的 attempt_count 或 problem 上的 attempts 字段记录付费尝试次数（schema 允许加列按既有 ALTER 先例），同一 problem 实际付费尝试达上限后拒绝。
