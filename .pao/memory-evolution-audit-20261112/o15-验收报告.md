## V4：请求关联与 token 用量

[脚本](evidence/o15-v4/run-v4.mjs)、[结果](evidence/o15-v4/evidence.json)。一次真实请求记录 totalTokens=1200；返回 requestId、reservation idempotencyKey、appendUsage 关联一致。预留 0.05 被以 settled/0 结算。

按[成本计量口径](优化任务.md#成本计量口径)，该次成本为已知的 1200 token，应计入请求、任务及后台用量。SDK cost 由模型费率计算，缺少单价仅令金额估算不可得；不能把 1200 token 视为未知或零成本。

现有账本预留 0.05 并按金额结算，尚不支持新的 token 额度语义。AF05 需接入 token 预留、实际 usage 结算、缺用量时保留占用，以及缓存/推理字段不重复计数；已有请求身份关联证据继续有效。
