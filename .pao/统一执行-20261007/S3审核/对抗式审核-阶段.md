### P3（有效未关闭，阻断）

**P3-1｜帮凶 2 存在普通路径可触发：守卫「保存并继续」×保存时改名 → pendingAction 旧闭包整表覆写 onSaved 改名 → 死标签**

  1. 标签 B 为未落盘骨架（名称输入框可编辑，`recipe-canvas-editor.tsx` revision===null 才显示），用户把名称从「新工作流1」改为「MyFlow」（draft.名字 变更 → dirty）；

  3. 选「保存并继续」→ `actions.save()`（:451）——save 内部先 `onSaved(saved.name)`（editor :519）**再**返回 true；
  4. onSaved（canvas-page :645-670）fire-and-forget 发出 setWorkflowTabs **#1**（本标签 title/recipeName → MyFlow），并删除骨架槽、setSelection、refresh；
  5. save 返回 true → `.then` 里执行 `pendingAction()`（:453-457）→ changeTabs 用**旧闭包的 workflowTabs** 发出 setWorkflowTabs **#2**（本标签仍是 新工作流1）；
  6. 主进程 `setWorkflowTabs` 为**整表替换后到者胜**（`app-store.ts:1280-1283`，`workflowTabsProblem` 不校验名字一致性），IPC 同帧 FIFO → #2 覆盖 #1，**改名丢失**；
