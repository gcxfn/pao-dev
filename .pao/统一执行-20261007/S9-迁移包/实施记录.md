## 一、工具落点与子命令面

| 件 | 路径（PAO/packages/coding-agent/ 下） | 说明 |
|---|---|---|
| 迁移核心 | `src/pao/migration/migrate.ts` | 定名表代码化映射表（导出可审计）＋单文件规划纯函数 `planCardMigration` ＋目录级执行 `runCardMigration` |
| 会话清单 | `src/pao/migration/sessions.ts` | `listSessionDirs`：逐目录报 jsonl 数、字节数、最后修改时间；只列不删 |
| CLI 入口 | `src/pao/migration/cli.ts` | 独立入口，不挂扩展注册表；`node src/pao/migration/cli.ts …` 直跑（Node ≥22 type stripping） |
| 测试 | `test/pao/migration-migrate.test.ts`、`test/pao/migration-sessions.test.ts` | 20 用例，含子进程杀进程演练 |

子命令：

```
migrate --root <目录> [--dry-run] [--backup-dir <目录>] [--sleep-ms <毫秒>]
list-sessions --root <会话根目录>
```

- `--root` 必填，缺省拒跑（退出 2），不猜默认。
- 迁移对象＝root 下递归匹配 `卡0*\d+-*.md` 的卡文件（与 listCards 同模式）；逐文件结果与汇总以 JSONL 打 stdout。
- 备份：转换前先备份原件；缺省目录＝目标根同级 `<根名>-migration-backup`（不得在根内——重跑会迁移备份本体，工具对此显式报错拒绝）；首份备份不随后续运行覆盖（保证可恢复副本始终是迁移前原文）。
- 失败语义：实跑遇任一 conflict/error 即停（不全量提交；幂等重跑续上），退出 1；dry-run 全量预览所有冲突后仍退出 1；全成功退出 0。
- 原子写：复用 `cards/atomic.ts` 的 `writeFileAtomic`（同目录 tmp＋rename，Windows EPERM 重试＋回退）。
- `--sleep-ms`：演练专用逐文件停顿，制造可杀窗口。
