## 3. 卡协议（D3：15+11+7 随迁；ParsedCard 独立工作包）

## 4. 值域枚举（D4：机器协议值随迁；持久面值与内容级 DSL 保留）

### 4.1 随迁值映射表

| 值域 | 现值 → 定值 |
|---|---|
| 卡状态五值 | 待认领→unclaimed、进行中→in_progress、已交付→delivered、失败→failed、取消→canceled |
| 优先级 | 高→high、中→medium、低→low |
| 档位 | 快→fast、主力→primary（内置档位名别名归一见 §6 例外 1） |
| 失败分型四值 | 瞬时故障→transient、缺输入→missing_input、能力不足→insufficient_capability、结果未知→unknown_outcome |
| worker 回执状态 | 成功→success、失败→failed、取消→canceled、未知→unknown |
| 节点控制动作 | 确认→confirm、暂停→pause、恢复→resume、裁定→rule |
| 部长保留词（动作禁用名单） | 绑定→bind、交卡→submit_cards、拆解结束→breakdown_done、判定→decision |
| 裁定结果 | pass/change/reject（已英文，不动） |
| 失败轴 | 卡面→card、部门标准→dept_standard、两轴→both |
| 知识条目类型 | 教训→lesson、导览→guide、做法→howto、评测→evaluation（磁盘类型目录名保留中文，写入层映射） |
| 路由 | 自动→auto |
| 实例流状态（仅回包投影用） | 运行中→running、挂起→hold（对齐桌面既有投影 hold）、已完成→completed |
| 裁定通道（仅回包投影用） | 主控→master、人工→manual |
| 留档标记 | 旧尝试留档→old_attempt、迟到回执→late_receipt（见 §3.2） |

### 4.2 保留（不迁）

| 项 | 理由 |
|---|---|
| 实例流状态/裁定通道的**持久面值**（控制清单/清单文件里） | 键随 D5 保留，值随键同进退；查流/推流回包若迁键，值在回包内读时投影为英文（单向、不回写） |
| 回边超限动作（停滞/修完这轮放行） | 配方语法（D5 保留面） |
| 机械验收三句式 `跑:`/`存在:`/`包含:` 与段标题 `## 机械验收` | 内容级 DSL 与卡面内容，重写等于改写全部存量卡的验收文本 |
| 回执「结果」惯例值（完成/失败/部分完成） | 自由字符串、代码无比对（grep 证实仅存在于描述文本）；属卡面内容，保留中文惯例 |
| 知识条目状态值（待验证/待复核/正式…）、摩擦场景值（打回/重试到顶/升级人/扇出取消） | 只存在于运行数据文件（D6 保留面） |
| PAO_ROLE 值 | worker 已英文、部长已有别名 minister、主控缺省；不动，建议文档统一用英文别名 |

理由：上表随迁项都是 schema 字面值＋代码比较值＋卡面落盘值三处同用的机器契约；保留项要么嵌在用户内容里、要么只活在保留的持久面。风险：随迁值必须全表一致替换（statemachine.ts:88,112、receipt.ts:63、桌面 thread-control-state.ts:38、fanout/审计），并驱动桌面动作值（确认/暂停/恢复）同批切换。

## 8. 一次批准行与高影响定名

**批准行：回复「S9 全按默认」即锁定本表全部定名与处置，进入实施排期（ParsedCard 按独立工作包另切）。要改单项，指出条目号即可（例：「③ 目标不拆分，统一 target」），其余按默认。**

最值得亲自过目的 5 个高影响定名：

1. **卡号**：默认拆两层——工具参数（字符串引用）`card_ref`，卡协议数值字段（Receipt/ParsedCard/QueueCardView/WorkerReceipt）`card_no`。备选：全统一 `card_ref`（数值字段叫 ref 略怪）或改 `card_id`。影响所有工具 schema 与卡文件。
2. **卡目录**：默认 `cards_dir`（复数，目录下多卡；桌面投影 cardsDir 同款）。备选 `card_dir`。17 个工具复用，改一次定型。
3. **目标**：默认按语义拆两名——卡/节点任务目标 `goal`，判定打回的回边目标节点名 `target`（同中文键两义，control.ts:501 证实）。不拆则模型须靠上下文区分，易混。
4. **档位值**：默认 快→`fast`、主力→`primary`；与用户在 档位.json 自定义的档名（虚拟模型 id，模型可见）同屏出现，拼写口味由用户定。
5. **状态五值中的两个**：已交付→`delivered`（备选 done/submitted）、取消→`canceled`（美式拼写；若团队习惯英式须全库统一 `cancelled`）。状态值是模型复述频率最高的词。
