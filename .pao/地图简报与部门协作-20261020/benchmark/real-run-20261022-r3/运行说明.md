## 当前与结束后的入口

- [运行状态](status.json)：由控制器记录，不把“运行完成”等同于“验收通过”。
- [后台观察状态](watch-state.json)：控制容器状态、性能进程是否存活。
- [控制器日志](controller.log)：安装、模型执行和官方验收的运行日志。
- [三题结果](三题结果.md)：结束后自动生成，逐题链接官方 result.json。
- [资源采样](resources.jsonl)：每30秒采样的原始记录；首次差值、采集失败或无法判断的阶段保持未知。
- [性能摘要](性能摘要.md)：结束后生成 CPU 采样峰值、内存首末值与采样峰值、进程数及缺失范围。

资源监控只采集本轮明确名单中的容器，记录容器 CPU、内存、进程数、网络和磁盘读写；Node 进程分为 PAO runtime、题目进程和无法归类的进程，再按角色/部门统计。PAO 与题目构建器、任务服务分开归因；监控不额外调用模型或改动题目。持续高占用、内存增长是调查线索，不能仅凭一个峰值判断代码结构。

## 后台与停止
