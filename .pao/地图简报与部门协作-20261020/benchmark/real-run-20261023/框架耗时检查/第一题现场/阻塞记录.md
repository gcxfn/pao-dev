# 基准开发流水线启动阻塞记录

- 时间: 2026-10-23
- 现象: `pao_start_flow(name="基准开发流水线", cards_dir=/app/.pao/benchmark/卡)` 两次被拒，报错
  「配方要求独立审核验证，但宿主不支持完整受管副本；须提供隔离验证能力后再启动」。
- 真实原因（源码证据）:
  - `src/pao/workflow/tools.ts:188-192` 要求：配方含「只读+审核」节点时，
    `worktreeHost.capability()` 必须返回 `create=true` 且 `baseline="recoverable-complete"`。
  - 本宿主（CLI）未安装受管工作树服务，`src/pao/index.ts:176-182` 回退到
    `createSingleRootWorktreeHost`，其 `capability()`（`src/pao/worktrees/types.ts:164-166`）
    返回 `{create:false, cleanup:false, baseline:"primary-only"}`。
  - 配方第 4 节点「审核」为 `只读: true, 审核: true`（`/tmp/harbor-pao-home/工作流/基准开发流水线.md`）。
- 处置: 不改内核、不伪造能力声明、不放宽验收规则；现场保留。
  改用同一套部门与卡机制手工串行推进（侦察→规划→实施→审核），审核按普通只读卡执行，
  并在报告中明确「审核非隔离工作树验证」这一降级事实。
