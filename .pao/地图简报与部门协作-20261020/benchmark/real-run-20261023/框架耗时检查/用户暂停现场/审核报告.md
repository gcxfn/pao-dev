## 5. 核查项 5：格式保持 —— fail（raw-text 元素不满足）

对**不含任何危险内容**的普通 HTML 做逐行 diff，多数差异确属解析规范化，但 raw-text 元素内出现**破坏性改动**。

### 5.1 普通文档：差异逐条可归因（这部分合格）

```
$ cat p.orig; python3 /app/filter.py p.html; diff -u p.orig p.html
--- p.orig
+++ p.html
@@ -1,4 +1,5 @@
 <!DOCTYPE html>
+
 <html>
 <head>
 <title>t</title>
```

逐条解释：

| 差异 | 是否属解析必然产物 | 依据 |
|---|---|---|
| `<!DOCTYPE html>` 后多一个空行 | **是**（bs4 序列化 doctype 后固定补 `\n`，原文已有 `\n` 于是成 `\n\n`），且已在 docstring 第 9 条声明 | `filter.py:47-49`；`str(BeautifulSoup('<!DOCTYPE html>\n<html>x</html>'))` → `'<!DOCTYPE html>\n\n<html>x</html>'` |
| `<meta charset="utf-8">` → `<meta charset="utf-8"/>` | **是**（void 元素自闭合，docstring 第 3 条） | 同上探针 |
| `<link rel="stylesheet" href="style.css">` → `<link href="style.css" rel="stylesheet"/>` | **是**（属性按字母序 + 自闭合，docstring 第 1、2、3 条） | `html.parser` 实测 |
| `<body class="page" id="top" data-x="1">` → `<body class="page" data-x="1" id="top">` | **是**（属性字母序） | 同上 |
| `<img src alt width height>` → `<img alt height src width/>` | **是** | 同上 |
| `&copy; &#169; &nbsp;` → `© © \xa0` | **是**（实体解码，docstring 第 4 条） | §4 输出 `'实体: © © \xa0 &lt;tag&gt; &amp;</p>'` |
| CRLF → LF | **是**（docstring 第 6 条） | §7 探针 |
| `<div hidden>` → `<div hidden="">` | **是**（bs4 布尔属性序列化） | §7 探针 |
| `<div>  <span>x</span>  </div>` → `<div> <span>x</span> </div>` | **是**（空白文本节点归一，docstring 第 8 条） | `w3.html` 实测 |
| `<p>a</p>\n\n\n<p>b</p>` → `<p>a</p>\n<p>b</p>` | **是**（同上） | `w5.html` 实测 |

### 5.2 raw-text 元素：实体被重复转义（不合格，缺陷 B-1）

当文档里存在 `iframe` / `xmp` / `noembed` / `noframes` / `plaintext` 且其文本里**含 `&` 或任何实体**时，输出会插入越来越多的 `amp;`：

```
$ printf '%s' '<iframe>a &amp; b</iframe>' > raw.html
$ python3 /app/filter.py raw.html; echo "run1 -> [$(cat raw.html)]"
run1 -> [<iframe>a &amp;amp;amp;amp;amp;amp;amp;amp;amp;amp; b</iframe>]
```

输入 1 个 `&amp;` 后，一次运行后的输出含 10 个 `amp;`。逐轮探针（`filter_html` 内部 settle 每轮在末尾再添一个 `amp;`，不是翻倍；`amp;` 计数依次为 2,3,4,…,9,10）：

```
$ python3 - <<'PY'
import importlib.util
from bs4 import BeautifulSoup
```

## 10. 缺陷清单（含最小复现、期望 vs 实际、严重级别）

### B-1（阻断）raw-text 元素内容被重复实体转义：破坏格式保持 + 非幂等

- 位置：`filter.py:242-253`（`serialize` 直接 `str(soup)`，未对 raw-text 元素文本做保护）、`filter.py:263-272`（settle 循环最多 8 轮，把单次转义放大成指数级）、`filter.py:57-58`（docstring 声称是固定点）
- 影响元素：`iframe`、`xmp`、`noembed`、`noframes`、`plaintext`（只要其文本含 `&` 或任何 `&…;`）
- 最小复现：

```
$ cd /tmp/audit/bugA && ./repro.sh
IN        : <!DOCTYPE html><html><body><iframe>a &amp; b</iframe></body></html>  (67 bytes)
run1 exit=0
run1 OUT  : <!DOCTYPE html>

<html><body><iframe>a &amp;amp;amp;amp;amp;amp;amp;amp;amp;amp; b</iframe></body></html>  (105 bytes)
run2 exit=0
run2 OUT  : <!DOCTYPE html>

<html><body><iframe>a &amp;amp;amp;amp;amp;amp;amp;amp;amp;amp;amp;amp;amp;amp;amp;amp;amp;amp;amp; b</iframe></body></html>  (141 bytes)
cmp: idem=FAIL (bytes grow every run)
```

- 期望：`<iframe>a &amp; b</iframe>` 内容语义保持为文本 `a & b`，且第二次运行字节不变（`cmp` 成功）。
- 实际：一次运行输出 10 个串联 `amp;`；第二次运行变 19 个；字节从 67→105→141 无界增长。
- 违反的卡面要求：第 5 项「格式保持」（差异超出"解析规范化"）、第 6 项「幂等性」（`cmp` 必须相同）、第 4 项「保留性」（iframe fallback 文本被破坏）。
- 建议修复方向（供实现卡参考，非本卡实施）：在 `clean_soup` 或 `serialize` 阶段把 `iframe/xmp/noembed/noframes/plaintext` 的文本子节点标记为不再转义的节点类（等价 `Script`/`Stylesheet` 行为），或直接对原始 `str` 做定点序列化；同时 settle 循环对"每轮都变长"的情况应报错而非继续放大。

### B-2（一般）无害注释被 `on…=` 子串误判删除

- 位置：`filter.py:83`（`_ON_PAYLOAD_RE = re.compile(r"on[a-z0-9_:-]+=")`）+ `filter.py:134-139`（在整段注释文本上做 `search`）
- 最小复现：

```
$ printf '%s' '<p>a</p><!-- options=1 controls the menu --><p>b</p>' > fp1.html
$ python3 /app/filter.py fp1.html; echo "exit=$?"
exit=0
$ cat fp1.html
<p>a</p><p>b</p>
```

- 期望：`<!-- options=1 controls the menu -->` 原样保留（不含任何事件处理器或脚本载荷）。
- 实际：注释整条消失；`buttons=`/`icons=`/`lessons=`/`persons=`/`reasons=` 同样中招（`&` CDATA 亦同）。
- 违反的卡面要求：第 4 项「保留性」中「无害注释」须保留。
- 建议修复方向：匹配事件处理器应要求 `on` 前是词边界/空白/引号（如 `(?:^|[\s"'])on[a-z0-9_:-]+=`），而不是裸子串。

### 观察项（不判 fail，仅记录）

- O-1 `data:text/javascript,`、`data:application/xhtml+xml,` 不在危险 scheme 列表（`filter.py:72-78`），原样保留。简报第 3 项只要求 `data:text/html`，故不判 fail，但属"移除全部 JavaScript"口径下的潜在缺口。
- O-2 `srcset` 属性中内嵌的 `javascript:` 片段未处理（浏览器不从 srcset 执行 JS，风险低）。
- O-3 `xlink:onload`、`xmlns:onclick` 这类带命名空间前缀的属性未被 `on*` 判定命中（`filter.py:162` 用 `lowered.startswith("on")`）。HTML/SVG 中事件属性不带前缀，实际风险低。
- O-4 注释/CDATA 的载荷判定用 `normalize()` 剥除全部空白后做子串匹配，`<!-- a javascript: b -->` 会因文本提及而被删（与 B-2 同源但性质更接近策略选择，已由 docstring 第 6 条声明）。
- O-5 不可解码文件报错时，stderr 先出现 bs4 的 `Some characters could not be decoded…` 告警行，属噪声。
