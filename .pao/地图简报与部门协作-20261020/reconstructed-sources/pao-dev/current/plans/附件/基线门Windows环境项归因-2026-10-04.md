## 2. 949 深因专节：`prints a pnpm metadata hint when self-update fails`

**一句话结论：断链点不在产品守卫本身，而在「测试夹具 fake pnpm.cmd 的批处理引号语义 × cross-spawn 7.0.6 在 Windows 对 .cmd 实参无条件加引号」——`pnpm root -g` 探测在 Windows 必然失配返回非零，`isManagedByGlobalPackageManager` 误判「非 pnpm 全局管理安装」，守卫按上游通用分支输出 `cannot self-update`，期待中的 `exit 23` 链路从未被触发。**

### 2.2 期望链路（测试装配，test/package-command-paths.test.ts:914-956）

1. `PI_PACKAGE_DIR=<tmp>\pnpm\global\v11\node_modules\@earendil-works\pi-coding-agent`＋`package.json`（模拟 pnpm v11 全局布局）；2. fake `pnpm.cmd` 置于 PATH 最前：`root -g` 时 echo 全局根并 exit 0，其余 exit 23（:922-927）；3. `process.execPath` 改指 `<tmp>\pnpm\bin\node`（:930-933）→ `detectInstallMethod()` 命中 `/pnpm/`（config.ts:84-88）→ pnpm；4. `update --self` 应走：`pnpm root -g` 取根 → 组装 `pnpm install -g …` → fake 对 install 调用 exit 23 → catch 里 `installMethod==="pnpm"` 追加 pnpm 元数据提示（package-manager-cli.ts:1085-1093）→ 断言 `exited with code 23`（:949）。

### 2.3 实际断链点（逐行）

1. package-manager-cli.ts:1058 `detectInstallMethod()` **确为 pnpm**（execPath 含 `/pnpm/`；probe [2] 验证），通过 ：1059 的 win32 npm/pnpm 白名单 → 排除「Windows 只许 npm/pnpm」守卫拦截。
2. config.ts:331 `getSelfUpdateCommand` 三条件：命令可组 ✓（pnpm 分支 ：131-151 必返命令）、`isManagedByGlobalPackageManager` ✗、可写 ✓。**断在第二条件**。
3. `isManagedByGlobalPackageManager`（config.ts:313-322）→ `getGlobalPackageRoots("pnpm")`（:236-241）第一优先 `readCommandOutput("pnpm", ["root","-g"])`（:132/237）→ `spawnProcessSync` → **child-process.ts:33-35 Windows 走 cross-spawn**。
4. cross-spawn 7.0.6（parse.js:36-59）：目标非 .exe/.com → 一律转 `cmd.exe /d /s /c`；escape.js `escapeArgument` **对每个实参无条件包裹双引号**（escape.js:36 `arg = \`"${arg}"\``，2024-12 安全加固的通用引号策略）。
5. 于是 fake pnpm.cmd 收到的 `%1`＝`"root"`（**含引号五字符**）；批处理 `if "%1"=="root"` 实际比较 `""root""=="root"` → 恒假 → 落到 `exit /b 23`。
6. 探测返回 23≠0 → `readCommandOutput` 得 undefined（config.ts:207-212）→ 兜底正则 `/^(.*[\\/]global[\\/][^\\/]+)[\\/]\.pnpm[\\/]/`（:134/239）要求路径含 `.pnpm` 库段，而夹具 v11 布局 `pnpm\global\v11\node_modules\...` 没有（该布局本就设计为依赖 `pnpm root -g` 应答）→ 全局根集为空。
7. `isManagedByGlobalPackageManager`＝false → `getSelfUpdateCommand` 返 undefined → package-manager-cli.ts:1072-1075 `printSelfUpdateUnavailable` → 上游通用文案「cannot self-update / not managed by a global pnpm install」→ stderr 无 `exited with code 23` → :949 断言失败。
