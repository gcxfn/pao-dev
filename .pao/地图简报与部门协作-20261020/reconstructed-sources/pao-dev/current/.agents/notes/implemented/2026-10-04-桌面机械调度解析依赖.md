# 桌面机械调度的表达式解析依赖

截至 2026-10-04，架构 §16.2 的任务字段已有定案，PAO 与桌面均无读取该任务目录的机械调度器。本机两仓依赖目录与锁文件未发现可直接复用的 cron 解析器。桌面上游 scheduled-tasks 是另一套通用模型任务，不能用它替换 PAO 文件真相或扩大到模型派单。

选择在桌面 `@pi-gui/pi-sdk-driver` 局部依赖中固定 `cron-parser@5.7.0`，仅解析表达式与计算下次时间；实际计时器仍属于桌面主进程，不引入 node-cron/bree、系统服务或数据库。该包是 MIT 许可，Node 要求 >=18，npm registry 已核实版本与许可；官方仓库仍维护 5.x，未自行实现 cron 语义。

官方依据：[README](https://github.com/harrisiirak/cron-parser)、[MIT 许可](https://github.com/harrisiirak/cron-parser/blob/master/LICENSE)、[发布记录](https://github.com/harrisiirak/cron-parser/releases)、[支持政策](https://github.com/harrisiirak/cron-parser/blob/master/SECURITY.md)。安装命令为 `pnpm --filter @pi-gui/pi-sdk-driver add cron-parser@5.7.0 --save-exact --ignore-scripts`，未安装全局工具、未构建。

机械巡检复用内核 `inspectHook` 与 `checkIndexConsistency`，只读输出问题。没有使用会改子索引并补行的 `inspectLibrary`，因为本阶段机械任务未获准自动修改正式知识。保温只做文件预读，付费嵌入保持关闭。归档只修剪本调度器成功留档，失败与未知留档保留。任务执行方式和验证边界见本轮 [实施记录](../../../.pao/后续执行-20261004/S5-机械维护调度实施记录.md)。
