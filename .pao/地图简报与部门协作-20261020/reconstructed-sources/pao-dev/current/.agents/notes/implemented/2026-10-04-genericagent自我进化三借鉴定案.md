# genericagent 自我进化机制借鉴定案（三点全采纳）

定案：2026-10-04（用户拍板「都要」）。状态：**设计定案，未实施**（随知识库/记忆线排期，见总册 §7）。原则：只进 PAO 原生知识库与常驻索引机制，不搬外部代码。

调研来源：genericagent（AgentVerse 自我进化 agent）自我进化机制扒取汇报（2026-10-04，主会话调研）。参考其记忆分层（L1 常驻索引／L2 全量知识库）与「执行才许写记忆」护栏。

## 采纳清单（三点全要）

1. **结晶判定显式化**：知识沉淀不再隐式发生——挂复盘/验收环节，由 owner（当值部长或主控）显式判定「本次是否结晶出做法」，判定为是才进知识库「做法」区，走既有三道锁（验证/去重/体积门）。防止流水账自动入库。
2. **常驻索引体积上限＋最短标识修剪**：常驻索引（对应 PAO 各部门 MEMORY.md 形态）设硬体积上限，超限按「最短可定位标识」修剪（保留一行指针、详情留在 L2 全量库）。护栏参照：L1 索引 ≤30 行。
3. **知识库条目带「验证出处」**：每条「做法」类条目必须记录验证出处——哪张卡、哪次真实验证过；无出处的旧存量条目标注「未验证」，不删除、不参与高置信引用。

## 护栏精华（一并吸收）

- **No Execution No Memory**：没真实执行过（只推理/只计划）不产生记忆写入。
- **写入决策树**：写入前依次过「是否执行过 → 是否与存量重复 → 是否可定位」三问，任一不过不写。
- L1 只放指针与触发词，正文永远在 L2；L1 膨胀即修剪，不整页重写。

## 落点（实施时对齐）

- 结晶判定：knowledge/ 写入入口＋复盘配方（workflow/distill 侧）。
- 索引上限：memory/resident.ts 常驻索引组装处。
- 验证出处：知识库条目 schema 加可选「验证出处」字段（不进卡协议 14 字段——知识库条目非卡）。

与既有定案的关系：不推翻 [外部技能包借鉴定案](2026-10-03-外部技能包借鉴定案.md)（机制层同路）；与 [记忆供应商插拔](2026-10-02-记忆供应商插拔与mnemosyne选型.md) 正交（本条管 PAO 自有知识库，不管供应商召回）。
