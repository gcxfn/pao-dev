# 桌面发行形态定案（setup 安装包＋现场同目录）

定案：2026-10-04（用户拍板「选 setup，放同目录」）。状态：**设计定案，未实施**（用户口谕「后面再做」，随桌面线排期，见总册 §7）。

## 定案内容

1. **发行形态＝setup 安装包**（nsis；上游 `package:win` 链现成，target 已含 nsis＋portable，取 nsis）。
2. **现场数据（部门/卡/pao配置）＝与安装后的 exe 同目录**（便携数据，不进 %USERPROFILE%）；首启找不到现场时引导选择。
3. **内核自带**：extraResources 带 fork PAO dist＋运行时解析指向包内——防回落 npm 原版 pi（symlink 不进包，`npm-package-fallback` 会丢全部 PAO 定制）。
4. **品牌改 PAO**：productName/appId/copyright 现为 pi-gui/上游署名，须改；保留上游许可证（MIT fork 惯例）。
5. **不做自动更新**（沿总册既有定案禁自动升级）：更新＝重跑 setup。
6. **内核版本随包冻结**：fork 改动须重新打包才进 app；dev 模式仍 symlink 即时联动，两形态并存。

## 实施要点（届时核）

- 三件主活：内核进包（extraResources＋解析）、现场目录（同目录定位＋首启引导）、品牌替换。
- **风险注记**：setup 若装进 Program Files 类受保护路径，「数据同目录」会撞 Windows 写权限——实施时验证；挡路则引导安装到可写位置（如 D:\），不静默改存 %USERPROFILE%。
- 退出语义不变：无系统态常驻（R05），关窗即全停（含维护子进程/pty/存盘 flush）；「四退出」验收项照总册执行。
