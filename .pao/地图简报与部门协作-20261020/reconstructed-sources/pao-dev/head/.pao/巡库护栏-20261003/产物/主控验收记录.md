## 审查发现与加固（主控补丁）

1. **裸点词逃逸（P2）**：`cd ..` 的 `..` 无分隔符不触发路径判定→放行→进程 cwd 挪出工作区后，后续全部相对词失锚。修：`需按路径判定` 增纯点/分隔符词规则（`/^[.\\/]+$/`）；`cd ..`/`cd ..\..` 现拒「工作区外」，`cd .` 仍放行（解析后即工作区本身）。
2. **Windows 尾随点/空白花活（P2）**：`type ".env "`（引号保住尾空格）绕过敏感文件名黑名单——Windows 文件 API 剥尾后读的是 `.env`。修：`命中敏感文件名` 比对前剥尾随点与空白；`.env `/`.env.` 均命中「敏感文件」。
3. **诚实声明补一条**：无路径参数的 cwd 类内建（裸 `cd` 回主目录）——判的是命令字符串不是进程状态，接线层应以锁定工作区为 cwd 执行每条命令。
