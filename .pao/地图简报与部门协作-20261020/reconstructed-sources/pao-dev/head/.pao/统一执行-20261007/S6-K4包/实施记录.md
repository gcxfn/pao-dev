## 二、契约字段表（K4+D2 契约正本，后续单独对抗审以此为准）

信封挂在查询输出顶层键 `信封`（kernel 侧中文容器键，与模块既有键风格一致；容器内四字段为冻结英文名）：

| 字段 | 类型 | 语义（冻结） |
|---|---|---|
| `version` | 字面量 `1` | 信封契约版本：字段结构变更才递增；消费方按此分派 |
| `sessionGeneration` | string，64 位小写十六进制（sha256） | 作用域代际指纹：同作用域身份稳定，**切会话/工作流即换值**。消费方切换后以新查询的代际为基准，事件代际≠当前代际＝旧作用域事件拒收 |
| `revision` | string，64 位小写十六进制（sha256） | 内容指纹：同代际下内容未变＝同值；**去重**用（消费方据此跳过重渲染/丢弃重复事件）；不含时间字段 |
| `publishedAt` | string，ISO 8601 | 本投影发布时间；每次投影都变，**不参与指纹** |

配套纯函数（同为契约，D2 经 re-export 调用、禁止自实现指纹——两侧指纹算法必须同源）：

| 函数 | 签名 | 语义 |
|---|---|---|
| `sessionGenerationOf` | `(scope: unknown) => string` | 作用域身份 → 代际指纹；身份对象含 会话/项目根/工作流实例 等键，任一变化即换值 |
| `contentRevisionOf` | `(payload: unknown) => string` | 内容（已剔除时间字段）→ 内容指纹 |
| `isStaleEvent` | `(eventSessionGeneration: string, currentSessionGeneration: string) => boolean` | 拒旧事件判定：不等＝旧作用域事件，拒收（不串标签/会话） |
| `buildEnvelope` | `(scope, payload, publishedAt) => ViewEnvelope` | 组装信封（scope 定代际、payload 定内容指纹） |

语义红线（正本 §S6 第 4 条原文落实）：**版本是传输/视图信息，不能替代卡状态**——信封纯函数零状态零落盘，卡与控制正本仍是唯一真相；generation 是相等性比对基准（不等即拒），不做同代际内事件定序，同代际内消费方以查询回放为准（拉模式）。
