## ⑦⑧ 根因（确认放行恒 disabled）

失败截图（06 轮产物，`test-results/core-workflow-control-主控暂停…/test-failed-1.png`）显示错误消息原文：

> Workflow tabs were not saved: workflow tab 56e86c47… controller session is already bound to tab 80e59f00… (01a11cd7…)

链路：选中实例后控制面板的 `sessionId=identity?.sessionId`（canvas-page.tsx:670），而 identity 只从 `activeTab.controller` 派生（:234）→ 激活标签是「运行记录」标签（无 controller）→ `owns=false` → 渲染「打开原主控」；点击后 onOpenOwner（:673）把已被「主控」标签绑定的同一会话**再绑**到运行记录标签 → 主进程守卫 workflow-tabs.ts:105（一个主控会话只许绑一个标签）拒绝保存（app-store.ts:1279）→ 绑定不变 → `owns` 恒 false → 确认放行恒 disabled。节点「任务·第1轮·等待部长会话绑定」，requiresConfirmation=true 不是卡点。

定性三选一：**产品缺陷立案**（UI 提供必败路径：打开原主控尝试二次绑定而非激活已绑定标签）。修法方向供专卡参考：①打开原主控改为激活已绑定标签；②owns 判定改用 control.ownerSessionId 全局匹配；③守卫放行同会话只读绑定。归属：运行控制域专卡（补跑批已立），本批只定性不修。:20 与 :250 同根。
