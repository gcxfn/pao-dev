# 桌面端开发规则

本目录遵循父目录 AGENTS.md 的长期规则；本文件只保留桌面端专属约束，不记录当前进度、版本或验收数字。

## 边界

- 桌面端是内嵌 PAO 内核的独立应用：界面负责展示与交互，宿主通过 SDK/窄适配接口调用内核；不依赖全局 CLI，不复制任务状态、派发、预算或停止规则。
- renderer、main、preload 和 `pi-sdk-driver` 通过窄接口通信，避免把 Node 能力或内部状态直接暴露给页面。
- driver 保持对共享内核 SDK 的薄封装；发行物携带匹配内核与运行依赖，不依赖源码仓绝对路径。需要进程隔离时使用内嵌宿主入口，不借 CLI 参数解析或终端渲染作为运行接口。
- 可独立功能按模块组织，通过现有装配入口接入；没有真实需求时不新增插件框架或第二套运行时。

## 工作方式

- 非简单改动先写清目标、边界、用户可观察结果和验证方法。
- 一次只改一个明确边界；不要把无关重命名、格式化和功能开发混入重构。
- 桌面功能完成前要在真实 Electron 界面验证；单元测试不能替代真实界面验证。
- 不删除用户会话、缓存、截图或临时产物；不覆盖其他工作区改动。
- 新代码标识符使用 ASCII 英文；中文仅用于注释、界面文案和文档。
