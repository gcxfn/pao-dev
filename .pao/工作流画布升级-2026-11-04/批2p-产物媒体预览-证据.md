## §5 批 2p 验收逐项

1. **图片/SVG/可播放视频/无法解码视频/文本/超20MiB/缺失文件** ✅——`artifactPreviewView` 纯函数分支：image/video（dataBase64 缺失→undecodable 兜底不渲空 src）/text（truncated 标记）/other（只给打开）；failed 9 码逐码 i18n 文案；超 20MiB 主进程 stat-only 返 `too-large` 只给打开；missing 用例已补测。
2. **展开前不读内容** ✅——折叠态只渲路径/attempt 行 + 「预览/打开」按钮，不发任何请求；点「预览」才发 getCanvasNodeArtifact（单条一次，不批量预拉）。
3. **同名相对路径不猜基准** ✅——`basisRootOf` 三分支：attempt 绑定→executionRoot；无绑定→projectRootForCards；损坏→`read-error` 显式报因不回退，与内核 `validateReceiptContent` 同口径。
4. **同路径多 attempt 来源保留** ✅——`artifactSourceNote`：attempts 合并或含非最新 attempt 时显示「当前路径内容（来源 attempt …）」；latestAttempt 接线后单一历史 attempt 也能标。
5. **重读前不抢换预览** ✅——openSeq+request-key 双守卫：响应回来时序号已推进或身份已变即丢弃；「重新打开」才取新内容；普通刷新不抢换。
6. **资源释放** ✅——data: URI 无句柄无需 revoke，state 替换/卸载即释放；预览状态以产物身份+打开时刻为键，切产物/折叠/切详情键丢弃载荷；代码注释留档「若视频改 blob URL 须 cleanup revokeObjectURL」。
7. **右侧放大与窄屏布局** ✅——Electron spec 断言图片缩略点击在右栏放大（展开类名切换，无 dialog/modal）；1280×900 与 900×900 两档截图均断言 `scrollWidth<=clientWidth` 无横向溢出（见下节）。

## 存疑/如实标注

- **真实 Electron 界面 spec**：渲染分支经 unit spec（renderToString 纯函数断言）+ 主进程核对链单测覆盖；Electron 层可实证切片已由 `tests/core/canvas-artifact-preview.spec.ts` 落（见下节）。SVG 内容保真度、symlink/越界核对、旧预览切走丢弃等非界面可证条目归 unit spec（canvas-artifact-query fake-fs 全链 + canvas-node-detail），界面 spec 只抽样端到端可感知行为。
- **actionError 点击触发断言**：渲染层 renderToString 不跑 effect/事件，doOpen/doReveal 失败回显的端到端断言留 e2e 层；渲染分支（actionError 渲染 role=alert）可由 unit 断言。
- **latestAttempt 0/无卡缺省回退**：`detail.card.attempts>0` 才传，缺省时组件按该路径 attempts 最大值兜底——单卡最新 attempt 行的标注依赖回退值，语义仍正确。
- **onOpen/onReveal 外部回调**：无 CanvasMutationResult 返回契约，失败反馈只对默认 api 路径生效；回调路径保持现状。
