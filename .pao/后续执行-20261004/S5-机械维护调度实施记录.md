## 实现与边界

- 桌面窗口建立后启动一个进程内调度器，关闭最后窗口（含 macOS）和 before-quit 均停止；无 `PAO_HOME/定时` 时不创建目录、任务或子进程。没有系统注册项。
- 原任务字段保持 `id/名/prompt/cron/工作目录/工具白名单/repeat/enabled`。当前明确支持工具白名单且仅含一个 `巡检`、`归档`、`保温`；未知工具/坏字段拒绝，配置失败有留档与 Windows 通知。`repeat` 只支持布尔值，未知形态拒绝，不猜旧语义。
- **prompt 只是任务说明，不交给模型、不解释执行。** 每份留档都说明该事实，并明确自然语言任意任务未验证。没有派卡、启流、代码写入、shell 执行、入库、模型或嵌入入口。
- 巡检调用 PAO 同一 `inspectHook/checkIndexConsistency` 规则，只读报告，不自动补索引、落巡库卡或更改知识正文。保温仅预读本地知识文件，明确不是持久语义索引刷新。
- 归档仅修剪机械任务已有成功留档，每个任务保留最近 30 份；失败、未知、人工文件保留。修剪范围固定于 `PAO_HOME/定时/留档`，不删项目或知识条目。
- 全调度器同刻最多一个子进程；留档 `wx` 独占创建防重复到期执行，单次任务有历史留档即不自动重跑。关闭期间不补跑；重新启用单次任务需明确换新 id。定时 JSON 是任务正本，留档是执行记录，没有第二数据库。
- worker 是 Node 机械进程，无子孙进程入口。必须连接 IPC，等父进程安装监听后收到 execute 才执行；父进程死亡导致 IPC 断开立即退出。正常关闭还直接 kill 唯一受管子进程；30 秒超时终止且不报成功。独立会话进程不受影响。
- 输出回执与退出码同时成立才记机械操作完成，异常退出/关闭/无回执都不记成功。结算写入失败有显式通知。没有对成功结果静默默认。
