# S2 验收中取消修复

截至 2026-10-04。未调用模型、未 build、未修改冻结 dist。

## 已修改

- workflow/auto.ts：worker 收齐回执后、差异核查后、机械验收后重新核取消；取消直接上抛，不继续交付/交卷。
- cards/verifier.ts：signal 从正式验收工具和自动链传入；项目定位 git、沙箱 robocopy、逐条验收命令接取消。取消不归类为普通验收失败继续跑下一条；落已交付与写验收正文前检查。
- cards/process.ts：提取原 verifier.runProc，为验收/交卷共享。继续复用 worker/kill.ts 的 PID 树杀，不另造平台清理；等待树杀与 execFile 回调后才结算取消。原命令正常/非零/不存在/超时语义保留。
- cards/delivery.ts、baseline.ts：差异读取与交卷 git 接 signal，重试及下一条 git 之前检查；基线取消不吞作普通不可用。各原超时未扩。

## 验证

- 新真实 Windows 用例：验收 Node 产生孙进程并写心跳，就绪后取消；Promise 拒绝时父孙 PID 已退出，独立 Node 对照仍存活，下一验收命令没有运行，卡仍进行中且未写机械验收段。
- 新自动链用例：明确模拟 worker 成功返回同时 abort，真实卡和 git 仓库保留产物/历史，不验收、不交付、不新增提交。
- 第一批 verifier-run + workflow-auto-chain 45 通过（S2-取消验收回归.log）；新增自动链用例后 auto-chain/delivery-commit/baseline-snap/baseline-diff 四文件 71 通过（S2-取消交卷基线回归.log）。最后基线共享执行器的复核见 S2-取消最终定向.log。
- 全仓 tsc --noEmit --pretty false 本次无诊断（S2-取消接线类型检查.log）。独立审查交 s3，未据此标记完整验收完成。

## 边界

真实树杀测试仅 Windows；POSIX 复用既有 killTree 的能力边界，没有声称新增跨平台孙进程保障。取消发生在 git 提交已经实际完成之后不能倒退历史；阶段前检查阻止尚未开始的交卷，活命令取消会终止其登记进程树。没有自动重置暂存或撤销已有产物。
